| File | Historical source |
|---|---|
| `replay_suite.json` | Labeled synthetic replay set (13 scenarios) |
| `measure.json` | Retired `scripts/measure_history_rollup.py` |
| `evaluate.json` | Retired `scripts/evaluate_history_rollup.py` |

The former report path, `docs/performance/3.6.1-history-rollup-report.md`, is also absent from the current repository. The JSON samples remain unchanged.
