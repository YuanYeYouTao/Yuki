# Yuki 养鲲游戏说明

> 开局一只鲲，进化全靠吞。所有普通游戏命令都以半角星号 `*` 开头。

## 快速开始

```text
*签到
*孵化
*查阅属性
*命令菜单
```

第一次签到可获得 10 节操、1～3 颗蛋，并增加 5 点运势。然后用一颗蛋孵化自己的鲲。
同一天重复签到会扣除 10 节操。

群聊和私聊是两个独立存档；不同群之间也互不共享玩家、鲲、BOSS、拍卖和小游戏状态。

## 养成命令

| 命令 | 作用 |
|---|---|
| `*签到` | 每日领取节操和蛋，重置当日磨炼次数 |
| `*孵化` | 消耗 1 颗蛋孵化鲲 |
| `*买蛋 [数量]` | 用节操买蛋，默认蛋价为 5 |
| `*砸蛋 [数量]` | 消耗蛋抽取神器、幻化丹、鸡汤或复活药 |
| `*喂食 [数量]` | 用蛋增加鲲的体重 |
| `*磨炼 <数值>` | 按“数值÷当前体重”的概率成功；每天默认最多 30 次 |
| `*幻化` | 消耗幻化丹尝试更换属性 |
| `*渡劫` | 属性鲲消耗节操冒险提升体重，失败会阵亡 |
| `*喝鸡汤 [数量]` | 每碗恢复 1 节操 |
| `*放生` | 放生当前存活的鲲并获得节操 |
| `*复活` | 用复活药复活阵亡的无属性鲲 |
| `*查阅属性` | 查看鲲、资源和运势 |
| `*今日运势` | 查看砸蛋出货概率 |
| `*阵亡名单` | 查看最近 20 条阵亡记录 |

砸蛋的单颗出货概率为“当前运势÷2”。出货后再随机决定道具种类。无出货时运势减 2，
有出货时按获得的道具总数增加运势，最高 100。

## 鲲属性

| 属性 | 效果 |
|---|---|
| 无 | 没有特殊效果，可使用复活药复活 |
| 魑 | 免疫强袭 |
| 魅 | 免疫吞噬 |
| 魍 | 免疫攻击 |
| 魉 | 存活且体重低于 666 千克时，查看属性可恢复到 1000 千克 |
| 淫 | 被吞噬时可能反噬；攻击时可能恢复体重 |
| 馋 | 不能攻击；体重超过 1000 千克时可能因对应养成动作暴食而死 |
| 贪 | 部分行为可能不耗节操或获得额外蛋 |
| 惰 | 吞噬防御很强，并免疫强袭 |
| 怒 | 吞噬更容易成功，攻击可能触发致命一击 |
| 妒 | 对体重关系有额外防御限制 |
| 傲 | 对 BOSS 有伤害加成 |
| 悲 | 极低概率孵化，初始体重为本作用域榜一体重加 1000，不能幻化 |

## PVP

```text
*吞噬 @某位群友
*攻击 @某位群友
*强袭 @某位群友
*扔蛋 @某位群友
```

- 必须在消息里真实 `@` 恰好一位其他玩家；直接输入 QQ 号无效。
- 对方必须已经在当前群存档中成为玩家；吞噬、攻击和强袭还要求对方有存活的鲲。
- 正在拍卖托管中的鲲不能参加 PVP。
- 强袭需要神器；扔蛋需要蛋，命中后会降低对方运势。

## BOSS

SUPERUSER 先在当前群刷新 BOSS：

```text
/ai plugin run io.github.yuanyeyoutao.kun-game admin 刷新BOSS
```

群友可使用：

```text
*查询BOSS
*攻击BOSS
*吞噬BOSS
*强袭BOSS
```

击杀者获得 20 颗蛋和 100 节操；伤害榜前五名各获得 300 节操，击杀者也可以同时获得排行奖励。
BOSS 按上海时区跨日失效，新一天需要重新刷新。

## 拍卖

```text
*拍卖行
*出售 <起拍价>
*出价 <价格>
*成交
```

- 只有带属性的存活鲲可以出售；上架后由系统托管，不会继续留在卖家身上。
- 买家必须没有鲲、出价高于当前价，并且成交时仍有足够节操。
- 由卖家执行 `*成交`；买方扣款、卖方收款和鲲转移会一次完成。
- 上架满 5 分钟后，SUPERUSER 可以强制下架，鲲会安全返还卖家。

## 群小游戏

| 命令 | 玩法 |
|---|---|
| `*奥数比赛` | 抢答算术题 |
| `*数星星` | 数出黑色星星数量 |
| `*抄作业` | 倒序回复给出的字符串 |
| `*=答案` | 提交当前抢答题答案，例如 `*=42` |
| `*抽群主一个大嘴巴` | 多人参与的节操小游戏 |
| `*单挑群主` | 挑战当前群主角色 |
| `*当前游戏` | 查看正在进行的小游戏 |
| `*查骰子 [面数]` | 掷 2～100 面骰，默认 D6 |

## 私聊可用范围

私聊只支持：`签到`、`孵化`、`砸蛋`、`磨炼`、`幻化`、`查阅属性`、`今日运势`、
`命令菜单`、`喝鸡汤` 和 `当前游戏`。私聊不能使用 PVP、BOSS、拍卖或群小游戏。

## SUPERUSER 管理

管理命令不接受星号短入口，必须使用 Yuki 的插件长入口：

```text
/ai plugin run io.github.yuanyeyoutao.kun-game admin 鲲开
/ai plugin run io.github.yuanyeyoutao.kun-game admin 鲲关
/ai plugin run io.github.yuanyeyoutao.kun-game admin 小游戏开
/ai plugin run io.github.yuanyeyoutao.kun-game admin 小游戏关
/ai plugin run io.github.yuanyeyoutao.kun-game admin 刷新BOSS
/ai plugin run io.github.yuanyeyoutao.kun-game admin 重置局状态
/ai plugin run io.github.yuanyeyoutao.kun-game admin 强制下架
/ai plugin run io.github.yuanyeyoutao.kun-game admin 修改 <QQ号> <项目> <数值>
/ai plugin run io.github.yuanyeyoutao.kun-game admin 配置
/ai plugin run io.github.yuanyeyoutao.kun-game admin 配置 蛋价 7
```

完整清空当前群需要把群号作为二次确认参数：

```text
/ai plugin run io.github.yuanyeyoutao.kun-game admin 清除全群数据 <当前群号>
```

`重置局状态` 会保留玩家养成资源；`清除全群数据` 会删除当前群的全部养鲲存档。

## 当前玩法说明

磨炼失败显示的增重与实际变更一致。攻击、吞噬和强袭 BOSS 使用各自伤害规则；强袭会校验并消耗神器与节操。阵亡记录仅持久保留最近 20 条，已有超长记录会在状态维护时压缩。
