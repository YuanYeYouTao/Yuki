# Yuki 3.8.2 升级指南

本文件面向发布候选；在镜像与资产实际发布前，不假设 v3.8.2 可公开下载。

## 前置核对

1. 核对当前 Bot 镜像、有效模型配置和 schema。已处于0051时，本版不新增迁移。
   旧版本迁移仍须遵守[3.8.1升级指南](upgrade-3.8.1.md)，不能跳过预检直接stamp。
2. 保存并验证一致的 DB/WAL/SHM、配置和旧镜像备份；不要用git revert回滚数据库。
3. 检查生成模型声明支持思考且有效档位至少low；不支持的配置须显式修正，不静默
   关闭思考。embedding、TTS并非生成推理任务，不强塞reasoning参数。
4. 历史状态链/证据恢复不是本版自动迁移。不要把开发副本覆盖线上，也不要删除异常记忆。

## 部署与回退

从已提交代码在本地构建linux/amd64镜像，记录commit、镜像ID及传输文件SHA256。
验证本地smoke和发布检查后上传既有服务器；远端只加载镜像，不构建。
核对配置差异后仅重建Bot服务，不执行整个Compose down，不重启SnowLuma。
启动后观察至少15分钟，核对健康、QQ连接、队列年龄、批次实际结果和数据库完整性；
没有自然触发的功能标记未观察，不主动发真实群测试消息。

启动或核心功能回归时恢复旧Bot镜像及配置。没有数据损坏证据时，不用旧DB覆盖新消息。
不得通过清空上下文、记忆或重建embedding掩盖问题。

## 行为变化

普通提取可等待一小时；空提取/自省noop是正常结果。读取沿用历史共同群关系，
Evidence、private SELF和写入权限不扩张。自动召回最多四条，主动相关搜索保留补查能力。
详细变更及残余风险见[3.8.2说明](releases/v3.8.2.md)。
