## 取样与限制

账本按 ID ≤ 156646 固定上界，共 151002 条，发生时间覆盖 07-23 至 11-21。人物和事件从错称、纠正、来源归属及历史事实反查同会话原事件；规则从记忆证据及状态事件顺查投递。保留 trace 的补查窗口按结束轮的源事件取 115829–156646。对 2–350 字入站消息，“查、翻、搜、回看”与历史语境等窄筛命中 60 条，按源事件关联到正常结束轮的有 12 条；扩大到过去时间、说过、忘记等表述命中 712 条，其中 105 条可如此关联。两组有交集。另由纠正回复反向查投递与 turn_id，覆盖源事件为空及一条源事件有多个执行轮的情形。这些是定向样本，不用于估算总体失效率。
