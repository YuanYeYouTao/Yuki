# Yuki 意图召回修正任务书

本任务补充[记忆可靠性与强相关召回任务书](Yuki-记忆可靠性与强相关召回任务书.md)，
不替代自省、Dream、真实相关性校准与上线门槛。分支保持
`codex/memory-relevance-and-reflection`，版本 3.8.1，schema 0051。

## 不变边界

- 完整 Main Agent 使用正常 History、Rollup、Memory 和固定工具结构，不增加意图 Agent、
  独立短上下文、关键词正则分流或人格提示词修改。
- 不扩大历史共同群读取权限；Evidence、他人 private SELF、写入权限及 Plugin/Admin
  身份边界不变。意图与模型给出的账号不是权限证明。
- 不清空记忆/上下文、不重建生产 embedding、不修改用户配置，不推送、PR、发布或升级版本。
- 两份任务全部验收通过，才按原授权本地构建并只替换服务器 Bot；不重启 SnowLuma，
  不向真实会话发验证消息，部署后观察至少 15 分钟。

## C1：Session 回执与安全观测

普通 Main Agent 查询由 TurnMemorySession 拥有回执，移除该路径对旧空 memory_turn_id 的依赖。
已有预取回执则关联它；没有则创建零暴露 agent_tool 回执，不能因此虚构注入或启动 attribution。

查询成功、空、歧义、拒绝、基础设施失败、重复请求关联当前 session；缓存命中只计 duplicate，
不再冒充新数据库/embedding 查询。查询执行、实际进入下一次模型请求和最终使用判定分开。
结果注入前取消不能确认暴露。Plugin/Admin 纯读不产生普通聊天强化回执。

观测异常不能使成功读取失败；脱敏诊断不能静默缺失。生产只记录关联 ID、工具名、显式字段
存在性、枚举、实体数量、时间约束、结果数量及错误类别，不记录 query、实体名称、账号、正文、
完整参数或原始异常。历史缺失字段不推测回填，自动 purpose 不冒充主动模型参数。

## C2：统一意图与严格日期

Person/Group/SELF 共用参数解析，构造现有 MemoryQueryIntent。
显式 mode/purpose/entities/preferred_kinds/时间完整传到 Query Plane；既有 subjects 不被
授权目标集合覆盖，仅对明确解析目标补齐缺省重点。

- 非空 query 默认 hybrid，空 query 默认 overview，purpose 默认 recall。
- 非法枚举、日期、倒置或零长度区间明确报参数错误，不静默忽略或退回普通查询。
- 三种工具固定增加 temporal_constraint=strict|soft。有边界默认 strict，无边界不限制日期。
- Main Agent 根据已有时间上下文转换今天/昨天和明确日期。严格日期须带时区，区间起点包含、
  终点不包含；当地一天是当地零点至次日零点，不能先转 UTC 后仍保留当地偏移。
- strict 只查 valid_from 符合区间的事实；未知时间排除，不拿 created_at 或正文猜日期替代。
- FTS、短词 LIKE、向量及 overview 在候选截断前筛选。空结果不自动放宽为 soft。
- soft 仅表达宽泛时间偏好；无日期 overview、详情及权限保持原规则。
- 结果返回稳定 effective_query 摘要：实际 mode、purpose、时间边界及约束，不返回未授权目标。

只修改部署级固定工具/字段说明：人物身份、偏好与经历用 Person；群整体用 Group；自身用 SELF。
姓名用 display_name，真实 mention/reply 用 subject_ref，SELF 不代替人物解析。
指代由完整 Main Agent 理解，不由后端改成当前发言者。历史材料不足时主动补查，预取为空不等于
记忆不存在。正确总览无需高级参数；有界结果不等于全部存档。空结果可做实质不同的查询，
歧义澄清、明确拒绝不重试。不强迫每轮查、不增加循环次数。

## C3：验证、报告与文档

确定性测试保持最多 800 项，以相关行为矩阵替换旧测试：

- 三工具参数全链路、subjects 不覆盖、固定部署 schema；
- 时区、午夜、半开边界、未知日期、非法日期；三检索路径先筛选再截断；
- 零预取/正常预取、连续补查、缓存与取消回执；
- 空结果和权限拒绝区分，历史共同群/Evidence/private SELF 边界不变；
- 观测失败不损坏读取，不新增前置模型调用。

隔离副本真实 Main Agent 覆盖姓名、事件引用、指定日期、未知时间空结果、完整前文指代、本人
总览、零预取补查、歧义/拒绝八类。逐条保存问题、原始参数、有效意图、授权目标、结果及回复；
私有原文在仓库外受限目录，公开只有匿名结论。上下文充分而不调用及正确简单 overview 可以通过。
失败保留记录，修复后复测，不改预期，不用工具 success 或调用增加冒充正确。

所有验证共享原任务 48 次外部请求上限，开始时已用 3 次；主动补查最多 16 次，embedding、修复
和传输重试都计入总预算。在真实发送边界预占，预算耗尽不得继续或宣称完成。

每个提交跑目标测试、Ruff、mypy、diff 检查；最终跑原任务完整质量门。原任务仍须至少 60 个
合格真实样本、30 个独立验收样本及规定相关性指标，八类探测不能替代这些门槛。
报告分别给出模型选择、参数正确性、后端传递、检索质量、实际使用与统计覆盖；没有单一
“召回成功率”可以代表全部阶段。实施状态与失败证据见 [审计报告](memory-intent-usage-audit.md)。
