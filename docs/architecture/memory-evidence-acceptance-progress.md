## 已定位并处理的实现问题

- 人物工具的群限定说明明确为默认省略；处于群聊或 @ 成员本身不是限制到该群。
- 指定群范围拒绝保留 `permission_denied`、`retryable=false`，补充范围和未执行查询标记。
  不自动扩大查询，不改变历史共同群权限，不输出未授权目标信息。
- overview 原有占位词法分数被错误投影为词法命中：删除占位值，总览匹配状态改为未知。
- 自省字段语义说明原被 compact schema 删除：保留字段说明，明确持久事实与单次经历边界。
- 结构化长度修复加入允许上限、实际数量等数值诊断；不输出任意校验 context。
- 自省证据白名单仅包含实际渲染的事件；超过输入预算而未展示的事件不能被引用。
  非法引用最多定向修复一次，仍不合法则失败，不进入 mutation。
- 历史 Episode 从 `self_facts` 分入 `existing_episodes`，携带真实 kind；保留原有正文、
  记忆引用和完整上下文，不把历史流水账当作本轮写作模板或新证据。
