# 第三方人物事实与隐私边界

读取与写入权限分别核验，读取权不扩大写入权，也不开放他人的私聊原文或证据。第三方人物写入须当前真实群、明确主体及真实事件证据，沿 [Memory 修改入口](memory-change.md)执行。

当前 @、回复作者及受控唯一名称解析提供可信主体；正文保留真实目标 ID，模型上下文复用姓名资料显示，不以两套成员序号猜人物。名称和模型输入不能授权。

第三方事实写入当前群的 person_group，authority 保存 third_party，证据保留实际说话者与内部事件 ID。后台不按来源等级改写置信度、不自动 contest，也不因为本人后来发言自动替换旧事实。独立 CREATE 保留多个事实；明确 CORRECT 使用所选 fact ID 版本化，其他事实保持原样。

到期只根据事实明确的 valid_until；来源和年龄不构成自动失效判据。显式失效、隐私删除和已有外键流程仍执行真实授权，保留来源审计。
