## ACP是否漏做

原大任务书同时包含本期P1–P11与后续路线。§0第6项原文写明“ACP先A后B，两者都不进入本次交付”；§1.3排除ACP适配，§4将A放在P11之后、B放在S8，P11也明确将ACP验收C18留到后续。

| 方向 | 谁调用谁 | 原身份与会话边界 |
| --- | --- | --- |
| A：Yuki作为ACP Agent | Lody/Zed/Memoh等客户端 → 本地stdio适配器 → Yuki个人API | 适配器持设备凭据，ACP入口中每个session各有Conversation；不映射到QQ私聊或App主会话 |
| B：Yuki作为ACP宿主 | Yuki Work → 持久环境中的外部ACP Agent | 外部session是Work执行资源；Person、Work、journal、预算和回执不改由外部Agent裁定 |
