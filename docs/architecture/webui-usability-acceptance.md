## 原因记录

- 原“共享文件与已发布快照”列表读的是 artifact 索引；删除只删快照，工作区文件仍在。新主界面必须直接操作真实 `/workspace`。
- 原聊天 UI 只显示文本和附件超链接，出站纯图片消息的账本正文空，但 `segments_json` 留有原 `artifact_id` / `emoji_id`；需要经授权按这些内部 ID 读取。
- 既有分页使用有界游标，无真实总数与跳页；新的编号页面从授权数据源 COUNT 与 SQL OFFSET 读取，不在前端拼整库。
- 共享人格 `BOT_PERSONA_FILE` 的内容确实被替换入 `{{YUKI_PERSONA_CORE}}`，也参与 self reflection 与 memory dream；应保留。
