# 自主参与的连续决策模型

Yuki Host 在 `pyproject.toml` 与 `uv.lock` 固定独立库主线提交 `a55b8e5`。
本文件描述模型与宿主边界；实际线上版本以运行镜像、锁定依赖和数据库迁移记录核验。
控制器源码及参数见独立库的 `docs/autonomous-evolution.md`，宿主接纳与执行链见
[语义参与 V6 宿主接入](semantic-participation.md)。

## 决策对象

明确邀请与经 Jev 确认的直接续答沿请求路径提出机会。直呼 Yuki 只提高语义观察
优先级，不与 `@` 等价；无法归入已有讨论不阻止清楚的邀请。

非请求式 `open_group`、回忆、联系和无来源 `intrinsic` 由连续净机会值排序。
控制器把“本次不启动 SELF 回合”定为 0，只提出正值最高的一个机会。
0 是本次思考成本后的不行动基准，不是另一个随时间积累的门槛。
旧 `rate()`、`rates()`、随机 hazard 和 900/3600/1200 秒固定静默条件已从
独立控制器删除；旧快照字段仅供兼容迁移读取。

## 状态和方程

参与状态 `b=(O,H,Y,E,C)`、来源注意 `x_i`、支持 `S_i`、真人活动 `q`、
已确认 Yuki 发言 `p`、实际计算 `f` 和 SELF `engage` 倾向 `d` 由已核验输入与回执
推进。`h_i` 是同来源或对象被考虑后的熟悉度；`n` 仅由无来源 SELF 回合的
真实 `NO_REPLY` 增加。情绪自由文本不推断为数值状态，图扩散仍为 0。

真人群消息使慢速交流情境 `ℓ` 以 0.1 的饱和跃迁增加，无新消息时按
14400 秒时标衰减；它不同于 60 秒时标的忙碌痕迹 `q`。
SELF 倾向按 1800 秒回到中性。已接纳的无来源回合或真实 Yuki 发言会重置
自身恢复参考点；拒绝和 busy 不重置。无来源回合的 `NO_REPLY` 痕迹按
3600 秒衰减，避免放宽交流情境后反复空转。

```text
D(d) = 0.15 + 0.85(d+1)/2
R = N_Y/(N_Y+N_H)，分母为 0 时取 0
C = 0.08p + 0.04f + 0.02q
    + 0.1 min(1,N_Y+N_H)[R-0.35]₊ + 0.025
social_i = D(d)x_i/(1+0.15h_i) + 0.35b_H+0.25b_E-0.15b_Y-0.70b_C
opening_i = (1-exp(-gap_i/4))(0.1+0.9floor_i)
L_i = 1-(1-ℓ)(1-H_i)
U_i = S_i opening_i L_i[social_i]₊ - C - c_ind,i
```

`H_i` 是本群真人来源注意；纯记忆来源取 0。`S_i` 仅来自合法语义支持，
不会因群里热闹而凭空产生。`c_ind,i` 对回忆/联系为 0.05，对自然加入为 0。

无来源机会没有 event/memory 焦点，也不伪造 Jev 观测。其净值为：

```text
g = 1-exp(-(t-t_ref)/1800)
U_self = 0.55 D(d) g ℓ(1-q)(1-p)
         -0.04f -0.1 min(1,N_Y+N_H)[R-0.35]₊ -0.025-0.025-0.08n
τ_n·ṅ = -n，τ_n=3600 秒；获接纳无来源回合真实 NO_REPLY 时
n⁺=n+0.45(1-n)
```

`g` 随自身恢复上升，`ℓ` 随无人交流下降。当没有新真人消息时，
`ℓ→0` 且 `g→1`，所以 `lim U_self=-0.05<0`。有来源自主候选的本群
真人注意也会衰减；纯记忆不能单独复活沉寂群的公开机会。
这保证极久不活跃的群自然回到安静状态，**没有**“沉默满几小时禁言”的硬判断。
近期有足够交流背景的群可在数小时空档出现正值，但 proposal 不等于发送。

## 宿主边界

合法来源版本、讨论停止、群授权、唯一 owner、generation、Presence、活动 Work
和发送权限仍由 Host 在接纳或执行处核验，不转成效用分数。`intrinsic` 使用明确的
无来源类型和 SELF 主体；主 Agent 可以工具行动、显式 `send_message` 或 `NO_REPLY`。
实际发送、计算和 `NO_REPLY` 分别回馈控制器；未发送的模型正文不计发言。
宿主在接纳时阻断 proposal 之后到达但尚未评分的真人输入，避免旧讨论的关闭或停止
消息已到达时接纳旧机会。已接纳 run 按原 ID、Work 与回执恢复，不排队补发停机
期间的假想机会。

## 冻结回放及限制

独立库两条各 30 天的合成轨迹含 15,952 条真人形状消息和 41 段超过 6 小时的
真人空档。调整前后总 proposal 为 2,679 → 3,568，无来源机会为 118 → 1,007，
距上一条真人消息的最远间隔约 32 分钟 → 5 小时 52 分钟；两版超过 6 小时的
空档中均为 0。执行器对所有 proposal 返回记录型 `NO_REPLY`，实际 QQ 发送为 0。
前后报告见独立库的 `docs/evidence/autonomous-evolution-v1-replay.json` 与
`autonomous-evolution-v2-replay.json`。消息时间与规模只按服务器私有只读聚合校准，
正文和语义标签都是合成的；这些次数不能证明真实发言率或社交质量。
