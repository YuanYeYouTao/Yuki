# 自主参与的连续决策模型

2026-09-23。本文是连续模型设计与实施对照。独立库提交 `d571596` 已实现核心方程，
Yuki Host 此开发分支在 `pyproject.toml` 与 `uv.lock` 固定该完整提交，并已按固定版本
运行接入回归；合并及上线状态仍须分别核验。现行生产行为以
[语义参与 V6 宿主接入](semantic-participation.md) 和实际部署版本为准。
设计参考 [V4 任务书](Yuki_Autonomy_System/Yuki_Autonomy_System_Taskbook_V4.md) 的连续状态与可为空决策、
[现行 V6 接入合同](semantic-participation.md) 的语义证据与参与状态；
不沿用两书的逐候选积累、滞回阈值或随机强度积分。

## 改造前的断裂

改造前的独立控制器计算了 O/H/Y/E/C、来源注意、活动与计算痕迹，但 `advance()` 对有来源候选
直接按 `value × floor` 取最大值；`rates()` 的连续评分只供诊断。无来源 `intrinsic`
另由静默 900 秒、距上次尝试 3600 秒、距 Yuki 发言 1200 秒三项条件启动。
因此当前数学状态几乎不决定自主回合何时发生，也不能解释为什么这一刻值得让 Yuki 想一想。

本设计让连续状态控制**是否启动一个有限的 SELF 回合及选哪个机会**。它不直接产生消息。
主 Agent 仍可查询、行动、显式 `send_message` 或 `NO_REPLY`；真实回执再反馈模型。
清楚的真人邀请属于回应请求：仍先经 Jev 判断邀请和开口机会，不能被自主成本分数否决。
直呼名字仍只是优先观察信号，不与 `@` 等价。

## 状态与可验证输入

一个 Conversation generation 保存下列状态。所有时间更新按实际经过秒数解析推进，不按午夜重置，
也不在重启后补发假想错过的机会。

| 状态 | 来源与演化 | 用途 |
| --- | --- | --- |
| `b=(O,H,Y,E,C)` | 现行 Jev 观测、确认发送与现行衰减核；无观测回 O，不凭时间生成 C | 某个讨论的邀请、已发言、互惠、结束依据 |
| `x_i`、来源支持 `S_i` | 合法来源的有界刺激和注意衰减；预测支持保持原范围与有效期 | 某个话题此刻是否值得加入 |
| `q,p,f` | 真人活动、已确认的 Yuki 逻辑发言、实际主模型计算；沿用指数衰减和饱和跃迁 | 打断、重复发言与资源占用代价 |
| `ℓ` | 真实群内互动留下的慢速情境痕迹；真人事件使其有界上升，无新事件时衰减到 0 | 无来源的群内自主参与是否仍有现实交流背景 |
| `d` | 有效 SELF `engage` 自报改变参与倾向，随后以 `τ_d` 回到中性基线；缺失不造自报 | 仅调节 Yuki 自身的主动性 |
| `R` | 现行短窗口已确认 Yuki 发言与真人消息的比例 | 超过参考值时增加代价，不要求补足发言比例 |
| `h_i` | 同一内容或对象被真实考虑后的短期熟悉度；只有可靠同源关系才能共享 | 降低反复提起同一内容的价值 |
| `n` | 仅无来源 SELF 回合得到 `NO_REPLY` 后跃迁，随后按 `τ_n` 衰减 | 表示这次查看后暂时没有可做的事；不是负面情绪或群友评价 |

`ℓ` 与 `n` 是这一版需要新增的两个状态。`ℓ` 是可核对的群活动痕迹，不是对群友
心理或在线状态的猜测。已有 `f` 只记录实际计算量，不能区分
“花了一次请求后确实做了事”和“想过后发现暂时无事”。若实测证明 `NO_REPLY` 已能由
现有成本充分解释，可以在消融实验后删除 `n`，不能为凑齐状态变量强行保留。

V4 的情感 `e/m` 尚没有可信的结构化输入：目前 `mood` 是自由字符串，实际提示只要求可选的
`engage`。本轮不从文字、工具失败或无人回复猜 Yuki 的情绪；先让 `d` 真正参与决策。
`κ` 保持 0，直到有经验证的来源关系和非零图扩散收益；有来源注意不能凭图创造事实。

## 候选与资格

1. **明确邀请与持续回应**：现行 Jev 分类、来源版本、讨论范围与停止边界继续决定资格。
   它们走已有快速回应路径；讨论归属不再是明确邀请的硬条件。
2. **自然加入讨论**：真人有面向群体的有效内容、尚有开口机会时形成来源候选。
   `M_i=1` 仅表示来源、范围、版本、未消费、未关闭、未过期均有效；`S_i` 表示直接或
   限定范围内的短期预测支持。未知不被重新归一化为高分。
3. **回忆或联系**：只使用获准的群/SELF 记忆、可核对的对象与 Jev 对当前情境的适宜判断。
   已认领来源和无回应联系不因时间过去重新变成新来源。
4. **无来源自发思考**：这是单独的 SELF 候选，没有 event/memory 引用，不伪造 Jev 结果。
   它的价值是“值得启动一次思考”，不是“已有可以发送的话”。主 Agent 可合法 `NO_REPLY`。

来源资格、全群明确停止、群授权、唯一 owner、唯一活动 Work、generation、Presence 与发送权限
仍是执行事实边界。它们不能改成软分数。清楚的真人邀请可以回应，但明确停止和权限仍必须遵守。

## 连续机会值

令 `D(d)=D_min+(1-D_min)(d+1)/2`，`d∈[-1,1]`。实际 `engage` 跃迁为有界值，
随后 `τ_d·ḋ=-d`。短时发言比例使用现行指数计数 `N_Y,N_H`，但须以
`m_R=min(1,N_Y+N_H)` 限制证据质量：一个很久以前的孤立 Yuki 发言不能让
`R=N_Y/(N_Y+N_H)` 永久等于 1。对有来源自主候选，在已合格的支持范围内计算：

```text
social_i = D(d) · x_i/(1+β h_i)
           + a_H b_H + a_E b_E - a_Y b_Y - a_C b_C
opening_i = (1-exp(-gap_i/τ_gap,i)) · [ε_o+(1-ε_o) floor_i]
H_i = 当前候选中经核验的本群真人来源注意；纯记忆/SELF 来源取 0
L_i = 1-(1-ℓ)(1-H_i)
cost = c_p p + c_f f + c_q q + c_R · m_R · [R-r_0]_+ + c_call
U_i = M_i · S_i · opening_i · L_i · max(0, social_i) - cost - c_ind,i
```

`floor_i` 仅来自有效观察或许可的短预测；缺失不默认“轮到 Yuki”。`gap_i` 只改变
什么时候开口较合适，不生成新的语义证据。`x_i` 已包含来源年龄衰减，不再叠加一份
含义重复的新鲜度惩罚。`L_i` 使新真人话题可以靠自身来源产生交流背景；只有旧记忆
或 SELF 来源的回忆/联系则依赖缓慢消退的群情境 `ℓ`，不会在群沉寂很久后仅凭一次
历史扫描突然公开发言。回忆与联系仍可使用各自的来源时标与独立行动成本。

无来源的**群内参与**需要两种相反的时间效应：距上次 SELF 思考越久，自身恢复越充分；
距真实群内互动越久，公开开口的情境依据越弱。设 `t_ref` 为最近一次**获接纳的无来源
SELF 思考**或 Yuki 确认发言的较晚时间；新 generation 首次启用时取初始化时间。
`ℓ` 从本群真实人类事件逐次更新，与快活动痕迹 `q` 使用相同的已核验输入，但用 V4 的
慢时标 `τ_dormant`：

```text
τ_dormant · ℓ̇ = -ℓ ; 真人群消息到达时 ℓ⁺ = ℓ+w_q(1-ℓ)
g_self(t) = 1-exp(-(t-t_ref)/τ_d)
U_self = I_0 · D(d) · g_self(t) · ℓ(t) · (1-q) · (1-p)
         - c_f f - c_R · m_R · [R-r_0]_+ - c_call - c_ind,self - c_n n
τ_n·ṅ = -n ; 仅在获接纳的无来源回合以 NO_REPLY 结束时 n⁺=n+w_n(1-n)
```

`g_self` 没有“满 900 秒才开放”的资格门；`ℓ` 也没有“超过若干小时就禁言”的
判断。短期忙碌由 `q` 抑制，中期 SELF 恢复可能使机会转正，长期没有真人互动则
`ℓ→0`。接受一次无来源回合立即更新 `t_ref`，使这项机会值下降；`busy/rejected`
未实际思考，不更新。真实工具行动和确认发送分别入实际回执；仅有模型生成文字不计发言。

这修正了上一稿的关键错误。上一稿在长期沉寂、其他痕迹衰减后满足
`lim U_self=I_0 D(0)-c_call-c_ind,self`，按示例数值为正，因此可能隔很久又唤醒并
公开发言。新式在**没有新的真人互动或其他合格来源**时满足：

```text
ℓ(t)→0，g_self(t)→1，其他短期痕迹→0
lim U_self(t) = -c_call-c_ind,self < 0
```

所以无来源群内机会的正值只可能处在有限的中间时段，而不会随沉寂无限积累。
在没有新真人事件时，来源候选的 `H_i` 也随真实证据减弱；纯记忆/SELF 候选满足
`H_i=0`，其 `L_i=ℓ→0`。新的人类互动会重新增加 `ℓ`，新记忆仅成为待评价的内容，
不能给群情境或无来源 `ℓ` 偷偷加值。内部 SELF 自省可以按自身工作机制继续进行，不借一个
沉寂群的发送权限来证明其必要性。

这个长期结论不依赖某个“沉默小时数”判断。由于 `M_i,S_i,opening_i,L_i≤1`，
`x_i,D(d)≤1`，且参与状态各分量有界，所有非请求式公开候选都有有限的社会收益上界
`B·L_i`。当没有新的本群真人事件，`ℓ,H_i→0`，故
`limsup U_i≤-c_call-c_ind,i<0`。对无来源候选同样有
`lim U_self=-c_call-c_ind,self<0`。若暂时忽略其他痕迹，恢复与衰减的乘积
`(1-e^{-t/τ_d})e^{-t/τ_dormant}` 在
`t*=τ_d·ln(1+τ_dormant/τ_d)` 附近达到峰值，随后自然降低；真实成本会改变正值区间。

这套分数是无量纲的**本次思考期望价值代理**，不是 Jev 正确率、发言概率或心理量表。
`I_0` 与各成本必须在冻结的回放集上校准；不能直接把 V4/V6 表中实验数值当生产最优值。
选择 `I_0` 时应让**有真实群内互动背景**的某些中期状态出现 `U_self>0`，同时满足
上述长期负极限。接受后 `g_self=0` 且 `c_call+c_ind,self>0`，保证不会因同一状态
立即再次启动。模型不承诺每个群或每段沉默都一定出现自主发言。

调整后的参数为 `D_min=0.15, τ_d=1800 秒, τ_dormant=14400 秒,
c_call=0.025, c_ind,self=0.025, I_0=0.55, τ_n=3600 秒, c_n=0.08`。
若仅为检查曲线形状，取 `ℓ(0)=1` 且 `d=q=p=f=n=m_R=0`，则
`U_self=0.31625·(1-exp(-t/1800))·exp(-t/14400)-0.05`。
它先随自身恢复转正，随后随群情境衰减转负；一次真实接纳会重置 `g_self`。
这不是承诺的发言时段：真实 `ℓ(0)` 取决于此前人类事件，通常小于 1，
`NO_REPLY`、其他痕迹和主 Agent 的选择也会改变结果。

## 从连续状态到离散行动

每次真实观测、执行回执、自报或本地时钟检查，重新计算合格自主候选及“保持安静”的价值 0：

```text
i* = argmax({0} ∪ {U_i : 合格来源} ∪ {U_self : Host 允许无来源 SELF})
若最大值 > 0，提出对应的单个 proposal；否则继续观察。
```

0 是本次不开主模型回合的基准价值，`c_call` 是真实资源与打断代价的代理；这里没有
独立的积累量、随机抽奖、`z_min`、滞回开关或“必须攒够几分钟”的第二层门槛。
候选同分使用稳定来源 ID 排序，避免重启改变选择。可用现行本地 tick 近似连续越过零点，
记录 tick 造成的实际延迟；不为了精确数学越界在 SQLite 写事务中做模型/历史工作。

一次 proposal 仍先持久检查点，再由 Host 原子接纳。已接纳来源按版本消费；无来源按
原 run 身份和 `t_ref` 处理。重启仅按保存的状态计算当前一次机会，不把停机期间“本来
可能发生”的机会排队补发。拒绝的同一 proposal 不得每个 tick 换 ID 重试；只有相关
来源、授权或宿主状态变化时再评估。技术去抖、唯一 Work 和重试回执是工程防重，
不是模型行为配额。

无来源 SELF 回合需要一段如实说明来源的后部上下文：这次没有真人请求，可以基于当前群
可见上下文与获准 SELF 记忆主动做有意义的事或发言，也可以 `NO_REPLY`。不得暗示有人
正在等回复、伪造话题或把最终正文自动发送。否则即使数值模型成功启动，主 Agent 也
可能始终选择沉默；这要通过实际行为单独验证。

## 参数取舍与实施顺序

| 来源 | 下一版用途 |
| --- | --- |
| V6 `τ_H/Y/E/C, ω, τ_x, τ_s, a_H/E/Y/C` | 保留参与状态、注意和社会机会的解释；先核对真实观测分布 |
| V4/V6 `τ_q/p/f, τ_d, D_min, β, c_p/f/q, c_R, r_0` | 保留连续恢复、熟悉度和实际行为成本；接入当前未使用的 `d/h` 前先核对可靠回执 |
| V4 `c_call, c_ind` | 作为一次 SELF 思考的资源/打断代价，标定单位与实测请求成本 |
| V4 `τ_dormant` 与现行 `w_q` | 用于慢速群情境痕迹 `ℓ`；与快活动 `q` 作用不同，需检验一个人偶然发言不会造成过强主动性 |
| 新 `I_0, c_n, w_n, τ_n` | 仅控制无来源群内参与的基本价值与 `NO_REPLY` 反馈；优先少参数、做消融 |
| V4 `η, θ_on/off, z_min`、V6 `Λ, B, H(t)`、当前 900/3600/1200 秒 | 从自主提议时机中移除；不换个名字重新放回来 |
| V4 `e/m`、非零 `κ` | 暂不接入行为决策；待输入可靠性和独立收益验证 |

实施应先在独立库完成状态、评分、proposal 和恢复，再在 Yuki Host 同步接入反馈、
固定依赖提交与 lockfile。保留现行 Jev 语义邀请、来源版本、接受事务和主 Agent 执行链。
若需要持久化新字段，按现有快照兼容规则迁移，不丢失已有 pending/run/停止边界。

验证至少覆盖：明确邀请迅速进入现行回应路径；讨论中安静但无来源不会把别人话题冒认为
邀请；活跃后的中等静默可能使 `U_self` 从负变正，而极久无互动且无新证据时再次为负；
新建或一直无人发言的群不会凭时间生成无来源群聊机会；极久沉寂的群不会仅因旧记忆
产生公开 recall/contact；一次接受后不会热循环；连续
`NO_REPLY` 会推迟下一次无来源思考，真人新内容或明确邀请仍可正常处理；撤回、停止、
owner 切换、重启和迟到回执不重开旧 run；多日虚拟时间与 tick 频率改变不会改变来源
身份和大量增加启动数。再用同成本离线回放与线上有限观察分别衡量合理发言、沉默、
重复/打断和真实请求成本。离线规则样本不能证明真实群聊体验。

开发回放使用独立库 `fixtures/group-chat-workload-v2-full.json.gz` 的两条 30 天合成轨迹，
控制器跨日连续，所有 proposal 只由记录器反馈 `NO_REPLY`：15,952 条合成真人消息、
41 段超过 6 小时的真人空档。原参数得到 2,679 次 proposal，其中无来源 118 次，
最大间隔约 32 分钟；调整后得到 3,568 次 proposal，其中无来源 1,007 次，
最大间隔约 5 小时 52 分钟，两版在超过 6 小时的空档中均为 0，实际 QQ 发送为 0。
两版报告分别见独立库的 `autonomous-evolution-v1-replay.json` 和
`autonomous-evolution-v2-replay.json`。该夹具按服务器只读聚合校准活动形状，
正文和语义标签是合成的，不能将 proposal 次数写成
线上发言或合适参与次数。另有 5 次控制器 proposal 落在尚未评分的同讨论结束/停止
输入之后；Host 接纳层的未评分新入站屏障必须继续保留。

**预期效果**：模型将真的随时间与回执改变自主思考时机，允许有近期交流背景的群在
合适的中期空档出现自发机会，同时让长期沉寂且没有新依据的群自然失去公开开口价值；
有新讨论时会依据语义、参与状态和开口机会判断；不保证每次启动都发言，
也不应把发言次数升高当作成功。是否达到希望的“突然主动说话、同时不烦人”，必须由
真实 SELF 决策和群内效果验证，不能由状态方程单独保证。
