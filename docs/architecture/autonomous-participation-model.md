# 自主参与的连续概率模型

## 在线调参

自主机会模型的可调系数、采样基率和时间尺度集中在
[`config/autonomous-model.example.json`](../../config/autonomous-model.example.json)。
将其复制为宿主机挂载的 `config/autonomous-model.json` 后，可原子替换该文件；
SemanticParticipationService 每次约两秒的采样轮读取内容散列，校验成功才把完整配置
应用到所有当前 scope。无需重新构建或重启 Bot。无文件时使用镜像内默认值；删除文件
会恢复默认值。无效 JSON、未知字段或越界数值会记录错误类别并在健康状态中显示
`model_config_error`，已生效的上一版参数继续使用；健康状态的 `model_profile`
是生效内容散列前缀。

热更新只改变之后的机会率，不重放旧消息、不重新计算已接纳 Work 或回执，也不累积
停机时的抽样。已裁剪的历史迹线不会因为调大衰减时标而恢复。配置涵盖非请求自主机会
的全部可调数学参数；权限、显式邀请、来源有效性和持久执行合同仍由各自模块负责。
升级此模型时须将挂载配置中的 `quiet_group_floor` 删除，并将旧的
`intrinsic_interval_seconds` 改为新基准值或重新校准；未知字段会按上述规则拒绝加载。
当前生产挂载配置沿用旧示例值，因此部署需要同步原子替换该文件。

Yuki Host 固定独立库修订并持有接纳、权限、Work、主 Agent 和发送。
本文件说明模型与宿主边界；具体参数与回放见独立库的
`docs/autonomous-evolution.md`。部署版本须以实际镜像、依赖锁和快照核验。

## 决策边界

Jev 确认的明确邀请或直接续答继续走及时路径。直呼 Yuki 只提高语义观察优先级，
不等同 `@`；无法归属旧话题也不能挡住真实邀请。非请求式群聊、回忆、联系和
无来源机会使用连续机会率。一次 proposal 仅表示可启动 SELF 工作，不是发送命令。

来源有效期、撤回、停止、群授权、唯一 owner、generation、Presence 和活动 Work
仍由 Host 按事实核验。控制器不产生真人消息、Jev 观测、执行权限或聊天正文。
Host 不在停机时补采样，不重放历史机会；原已接纳 Work 按原执行 ID 和回执恢复。

## 状态与反馈

真人活动 `q`、来源候选的慢群情境 `ℓ`、无来源机会的真人活动量 `H`、实际计算 `f`、无来源真实 `NO_REPLY` 的 `n`
和 SELF 结构化 `engage` 的 `d` 保留各自职责。自由文本 `mood` 暂时只作表达语境，
以后量化须另立有时效和审计来源的结构化参数。

每个确实启动主 Agent 的自主 Work 只计一个快慢时间尺度脉冲 `W_f/W_s`。
一次 Work 内发送任意条消息、分条或调用多个工具都不增加这个脉冲。
Work 有确认的公开发送时，才产生一份“尚未被接住”的暴露 `E`；未确认发送、
仅有 proposal 或模型 `NO_REPLY` 都不是公开表达。Host 使用真实
`chat_events.id` 与原 run 关联出站锚点，Jev 后续的概率观测形成接收反馈 `R`。
无回复时 `E` 平滑上升并最终自行衰退；没有真人输入不被伪造成明确拒绝。
同一 Work 的多条消息只增加可核对的锚点，不按消息数加重下一轮频率成本。

```text
z = -0.6 + 0.8d - 0.5q - 0.3f - 0.8n - 1.8W_f - 0.25W_s - 0.55E + 0.5R
H(t) = Σ_human exp(-(t-t_i)/172800)
A(t) = H(t)/(H(t)+20)
s = t - t_last_human
G(s) = (1-exp(-s/1800)) · exp(-s/64800)
λ_intrinsic = A(t) · G(s) · sigmoid(z) / intrinsic_interval_seconds
P(本轮无请求式机会 | Δt) = 1-exp(-λ_total Δt)
```

示例基准时间为 `14400` 秒，线上实际值以挂载文件为准；它是率的倒数，
不是调度 tick 或固定等待时间。

没有真人活动证据时，无来源机会率为零。活跃群冷场时 `G` 平滑上升，沉默继续延长时
`H` 和 `G` 一起衰减；不会出现“沉默累计越过门槛”或固定时间
禁言。近期已有自主 Work／无人回应会连续降低新 Work 的频率，不对**当前 Work**
设置消息条数或工具调用次数阀门。主 Agent 仍自行决定在该 Work 内发送、行动或
`NO_REPLY`。明确请求与确定日程的自动化不受自主长尾率控制。

旧 `g` 恢复项、`p` 短时发言惩罚、`N_Y/N_H` 比例和净值正数门槛退出决策。
旧快照字段迁移读取后丢弃，不依据旧正文或平台消息 ID 重建不存在的发送／回应。
现有快照没有 `H` 时，Host 在短时事件窗口之外，对当前代次最近五个活动衰减时标的已入账真人事件
时间做按小时聚合的只读初始化；之后迹线随快照持续演化。不重写历史聊天、不补采样或补发。

先前生产观察后曾放松慢 Work 密度、未获确认回应的暴露；本次移除长期沉寂底率。短时 Work
惩罚仍抑制连续启动。Host 在启动及运行期间发现当前获准群的会话代次，即使新代次
尚无绑定或真人消息，也建立新的控制器并按现行配置选择 owner。旧代次的 proposal、
消息与采样时间不带入新代次，停机期间不补机会。

## 验证边界

独立库单元测试覆盖按 Work 计数、多消息等价、真实锚点回应、活跃群冷场与沉寂衰减和恢复。
Host 回归覆盖 Social 回执从真实内部事件 ID 绑定到语义 run，并阻止 legacy
运行误绑定。两条 30 天合成轨迹分别模拟 `NO_REPLY` 和已公开发送却无人回应，
无来源机会分别为 25 次和 7 次。回放仅能检验模型机会分布，不能证明真实发言或 Jev／QQ 的社交效果。迟到回应、
交错聊天和长空白由定向测试覆盖；实际 Host 固定修订仍须联测。
线上社交效果与合成回放分开报告。
