## 匿名案例

- **I01，按姓名询问另一位参与者**：没有对应的主动记忆读取记录，直接答不认识；
  后续给出账号再问，模型调用 SELF 读取并作答。证明至少有一例补查触发不稳定；
  不能据此断言全部名称解析失败，或第二次回答都来自工具。
- **I02，询问当天经历**：调用 SELF 读取，但返回包含数周前的经历。
  尚不能区分模型未指定时间与后端时间软约束过弱；缺少当次参数，不作归因定论。
- **I03，讨论工作与摄影**：Person 查询返回饮食事实和饮食偏好。
  证明工具 success 不能视作召回相关性成功；尚未证明错误发生在 query 构造还是排序。
- **I04，询问本人有哪些记忆**：Person 读取返回 overview 结果。这是正确用途，
  不应为提高“复杂意图参数使用率”而强迫总览填写无意义实体和时间。

## 统计关联的代码证据

普通聊天打开 TurnMemorySession 后，`ChatService._build_context` 将
`persist_memory_exposure` 设为 false，由 session 在真实模型请求阶段创建回执。
这时 ContextAssembler 返回的旧 `memory_turn_id` 为空。

`AgentToolService._record_memory_tool_outcome` 仍向该旧 ID 记录查询结果；
`MemoryRecallReceiptRepository.record_tool_read_outcome` 遇到空 ID 直接返回。
session 的 `_observe_read` 收集暴露事实，但没有同步迁移这条查询结果计数路径。
所以“计数为零”不能证明模型没查，也不能用作权限拒绝率或空结果率的可靠分母。

### 夹具与统计限制

- 本轮冻结的是受控问题，不是严格历史时间点重建。副本上的当前 corpus、权限及现役完整上下文
  用于判断调用链，不可混入历史召回准确率或原任务独立验收集。
- 夹具把请求者显示名设成了测试标签，而历史仍是原名；V06 的两种名称搜索可能受此影响。
  因此不能把其全部多轮行为归因为生产模型退化。下一轮必须保留真实显示名再验证，不能修改
  本轮失败记录或通过重命名标签将其改判为成功。
- 工具查询执行、JSON 结果过大、实际进入模型请求与最终回复不同：V06 的原始检索次数不能
  当作有效暴露次数；V07 没有最终模型回复，不能算已使用。生产仍不保存完整参数来补猜历史。
- V02 是拒绝路径探测，不是成功 mention 路径的证明。预定的独立歧义/未解析场景未执行，
  八类场景没有全部验收通过。
- 本轮纯查询没有启动 attribution；其 skipped/disabled 不能计入“确认未使用”。

### 已据探测修正但尚需真实复测的部分

1. Person/Group/SELF 固定说明压进 Provider 的 240 字 compact 窗口，避免姓名与引用规则被截断；
   明确有界结果不能宣称全部存档。没有按消息动态改变 schema。
2. 日期字段明确当地零点例子，避免“先换 UTC 又保留原偏移”。后端不根据正文偷偷纠正合法参数。
3. 统一参数形状日志提前到目标解析前，拒绝/歧义也可诊断；结果日志包含数量。
4. 基础设施失败加入指标合法枚举，避免观测路径把数据库故障误变成 invalid_arguments。
   观测写入自身异常只留脱敏诊断，不破坏正常读取。

### 总览失败的后端修正

此前检索成功但 JSON 超过既有字符预算时，整份工具结果变成 result_too_large，迫使模型
猜更小的 limit。三种记忆列表现在在原预算内保留完整事实的排序前缀，明确标记截断及返回
数量；不修改正文、不新增条数限制、不改变权限或检索结果的全局排序。首条也放不下仍失败，
不伪装成零结果。预留了后续 grounding 元数据的大小。

第二轮私有结果核对：检索 100 条、返回 14 条，事实 ID 顺序与原始结果前缀相同，正文逐条
相同；含 grounding 的 JSON 为 7,561 字符，符合该轮 8,000 字符预算。未向生产写入事实。

### 零预取补查的分层结论

模型使用的意图为具体摄影主题、当前请求者、recall，参数正确进入 Query Plane，后端解析
到获准 Person/PersonGroup；不是意图字段丢失，也不是权限拒绝导致空查。
返回三个候选均为 semantic_match，没有词法命中，相似度约 0.443–0.473；内容为游戏设备
和图像模型等事实。它们是主动查询宽候选，并未经过自动强相关门槛。

模型没有把这些事实编成摄影经历，但“没有摄影记忆”的绝对措辞仍不能由一次有界查询充分
证明。base_rank_score=1 或较高 rerank_score 只是相对排名，不能当作强相关概率。
不能凭本例随意提高阈值、扩权、强塞当前人物背景或降低验收标准；仍需原任务冻结样本校准。
