# Yuki-QQbot 2.1.0

2.1.0 引入统一 Tool Kernel、通用 MCP Client 和麦当劳中国官方 MCP 预设。Core、Admin、
Automation、Plugin、MCP 使用同一动态 Planner scope、工具目录、Binding、并发协调与结果预算；
支持 stdio 和 Streamable HTTP，并以 Alembic `0019` 非破坏性新增缓存、Artifact 和无正文调用指标表。

默认 `MCP_ENABLED=false`，升级后原有行为不变。启用前阅读 `docs/mcp/configuration.md`，复制
`.mcp.json.example`，并通过环境变量提供 Secret。本版本没有新增 MCP 专属审批流程。

## 主要更新

- Planner 从固定工具组升级为动态 scope，Core、管理员、自动化、插件与 MCP 工具统一选择和执行。
- MCP 支持 stdio、Streamable HTTP、lazy/eager/keep-alive 生命周期、动态 `tools/list`、缓存、
  同名隔离、断线恢复、工具网关和标准 Annotation 覆盖。
- 超长工具结果统一写入有期限 Artifact，并通过 `read_tool_artifact` 分页读取；普通日志不保存
  Secret 或完整远端结果。
- 新增 `/ai mcp list|show|status|tools|search|refresh|reconnect|enable|disable|doctor|call`。
- 麦当劳预设接入官方 `https://mcp.mcd.cn`，覆盖菜单、营养、门店、活动、点餐、订单、优惠券、
  麦麦商城与积分能力。查询型工具并行调度，地址新增、领券、下单与兑换保持修改型串行执行。
- MCP 401/403、429、5xx、超时和网络故障返回稳定、可操作且不含 Secret 的诊断信息。
- 恢复完整 Yuki 外貌与生日设定，进一步缩短日常表达，减少长难句、括号动作和多余回复气泡。

## 升级与启用

```bash
git pull origin main
docker compose up -d --build bot
```

Docker 会自动执行 Alembic `0019`。只重建 Bot 不会清除 NapCat 的 QQ 登录状态。麦当劳 MCP 的
Token 申请、`.env` 配置和诊断步骤见 [当时的 MCP 配置](https://github.com/YuanYeYouTao/Yuki/blob/v2.1.0/docs/mcp/mcdonalds.md)。
