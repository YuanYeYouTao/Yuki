# Yuki 3.9.0 发布说明 / Release notes

<!-- release-baseline: version=3.9.0 schema=0119 -->

**发布日期：2026-10-15（UTC+8）。** 3.9.0 将聊天、主动行为、定时任务与持久工作统一到共同 Main，使用当前模型完成会话 Compact，并让正常任务收尾之后的原批次和程序继续完成获准工作。默认 direct 发行支持 Linux amd64 与 arm64。

本页覆盖 `v3.8.4`（`9c20ede6`）之后、产品截点 main [`030917b1`](https://github.com/YuanYeYouTao/Yuki/commit/030917b1c994c9306bc1176663e989462153e222)（#437，2026-10-15 05:41:22，UTC+8）的 **257 个已合并 PR**。发行文档在此截点上整理，其自身的 PR 不递归计入产品清单。下载见 [3.9.0 Release](https://github.com/YuanYeYouTao/Yuki/releases/tag/v3.9.0)，配置与迁移见 [3.9.0 升级指南](https://github.com/YuanYeYouTao/Yuki/blob/v3.9.0/docs/upgrade-3.9.0.md)。

## 3.9.0 的主要变化

### 共同 Main、长任务与工具回执

聊天、主动醒来、定时任务、插件与 Work 续跑使用共同 Main 和类型化 Agent loop。默认 direct 构建提供完整主工具声明，不加载 Monty；Code Mode 已合入主线，仍须显式选择 `codemode` target 并启用，沿既有执行器和授权执行。终端可直接调用。主要 PR：[#214](https://github.com/YuanYeYouTao/Yuki/pull/214)、[#218](https://github.com/YuanYeYouTao/Yuki/pull/218)、[#265](https://github.com/YuanYeYouTao/Yuki/pull/265)、[#308](https://github.com/YuanYeYouTao/Yuki/pull/308)。

Work 保存原目标、执行 ID、累计预算、私有协议和效果回执，支持父子任务、等待、续跑、主动完成与取消。删去固定开始通报、必须投递后才能结束、重复结果判“无进展”、额外恢复次数和耗时阈值等收尾门槛；新聊天和补充指示继续沿原任务处理。收尾只收拢真正所属的活动执行，时间、会话、插件事件和任务等待沿原条件保留，任务笔记不作为完成条件。取消沿原进程和沙箱执行登记处理。主要 PR：[#215](https://github.com/YuanYeYouTao/Yuki/pull/215)、[#228](https://github.com/YuanYeYouTao/Yuki/pull/228)、[#254](https://github.com/YuanYeYouTao/Yuki/pull/254)、[#255](https://github.com/YuanYeYouTao/Yuki/pull/255)、[#258](https://github.com/YuanYeYouTao/Yuki/pull/258)、[#286](https://github.com/YuanYeYouTao/Yuki/pull/286)、[#290](https://github.com/YuanYeYouTao/Yuki/pull/290)、[#376](https://github.com/YuanYeYouTao/Yuki/pull/376)、[#415](https://github.com/YuanYeYouTao/Yuki/pull/415)。

同一模型响应先 `complete` 再 `send_message` 时，后面的发送现在沿原回执正常执行。`wait`、`need_input` 与交接也先让原批次或 Code 程序收拢，再由共同 writer 落实决定；单项能力拒绝只返回该项回执，脚本可以继续处理它并执行其他获准步骤。真正取消或失败当前目标、来源或租约失效仍停止旧来源的新效果。恢复沿原调用键、VM、效果和累计预算继续，首次 Work 接纳与原调用回执、已付模型计量原子提交，跨分段媒体沿整批结果统一配对。主要 PR：[#437](https://github.com/YuanYeYouTao/Yuki/pull/437)。

持久子 Agent 继承 Main 的完整固定工具、核心提示与执行后端，按自己的真实来源和权限使用；嵌套子任务登记到实际父 Work，共用根预算。真实子问题接续仍可消费输入的父任务；父已经终态时保存问题并如实返回，子任务继续处理自身工作。等待和提问后的原程序可以完成保存、通信与交付，旧子任务也能按原编号查询、补充、取消和恢复，无需为管理它另建空任务。主要 PR：[#426](https://github.com/YuanYeYouTao/Yuki/pull/426)、[#437](https://github.com/YuanYeYouTao/Yuki/pull/437)。

已确认效果不因重启重做，未知发送结果继续保留并核对原回执；工作区或沙箱真实失败不会被记成成功。删除全局只保留 128 个终态 Work 的裁剪，保留发生记录及迟到结果依赖。恢复仍核验当前真实授权，读取内部任务编号不等于获得管理权限。主要 PR：[#182](https://github.com/YuanYeYouTao/Yuki/pull/182)、[#318](https://github.com/YuanYeYouTao/Yuki/pull/318)、[#319](https://github.com/YuanYeYouTao/Yuki/pull/319)、[#391](https://github.com/YuanYeYouTao/Yuki/pull/391)、[#392](https://github.com/YuanYeYouTao/Yuki/pull/392)、[#406](https://github.com/YuanYeYouTao/Yuki/pull/406)。

### 定时任务、群聊与合并转发

定时任务到点激活共同 Main，退出 static 直送、typed DSL、独立模型路由、创建时历史选择与第二套 cursor、恢复和扣费逻辑。固定文字提醒也由主模型处理，因而产生模型费用；旧任务升级保留可表达目标、版本、原发生和回执，无法直接转换的旧 DSL 保留原件并停用未来安排。长约束完整传入，尾部标记不再被截断。SDK 创建任务使用明确稳定的 `request_id`，同一次调用可创建多个独立任务，重试同一 key 返回原收据。主要 PR：[#296](https://github.com/YuanYeYouTao/Yuki/pull/296)、[#308](https://github.com/YuanYeYouTao/Yuki/pull/308)、[#412](https://github.com/YuanYeYouTao/Yuki/pull/412)。

群聊普通接话合并短时间内连续输入，真人邀请及时进入普通消息路径，已有 Work 的输入和等待处理保留优先关系；自主加入仍沿 SELF。全局与群级自动回复、主动醒来分别开关，热修改不会停止已接纳任务。参与反馈沿真实来源，不重写旧历史，也不保证每次机会发言。主要 PR：[#150](https://github.com/YuanYeYouTao/Yuki/pull/150)、[#151](https://github.com/YuanYeYouTao/Yuki/pull/151)、[#230](https://github.com/YuanYeYouTao/Yuki/pull/230)、[#313](https://github.com/YuanYeYouTao/Yuki/pull/313)、[#314](https://github.com/YuanYeYouTao/Yuki/pull/314)、[#408](https://github.com/YuanYeYouTao/Yuki/pull/408)。

合并转发按需读取：Agent 用外层消息的内部事件 ID 调用既有 `read_conversation_history`，取得原始第一层聊天文本。不会自动展开转发内容、为内层条目制造事件 ID，或递归打开图片、视频与嵌套转发。主要 PR：[#315](https://github.com/YuanYeYouTao/Yuki/pull/315)。

### 公共历史、本轮资料、Compact 与数据库

一个 Conversation 使用同一份公共历史；删除按当前说话人、个人配置、read scope、入口或请求合同重新分叉历史的链路。个人与 SELF 时区配置退役，当前时间和历史统一默认 UTC+8，明确指定的调度时区继续保留。当前图片不再清空整份公共表示缓存。公共自动任务笔记与观察摘要退出，原 Work 私有记录、协议、来源、DAG 和产物引用保持原件。本轮执行的闲置时间对象和空透传一并移除，当前时间由工具在调用时读取；保留缓存实验的 compact 与数据库重开入口也已同步修正。主要 PR：[#316](https://github.com/YuanYeYouTao/Yuki/pull/316)、[#317](https://github.com/YuanYeYouTao/Yuki/pull/317)、[#393](https://github.com/YuanYeYouTao/Yuki/pull/393)、[#346](https://github.com/YuanYeYouTao/Yuki/pull/346)、[#404](https://github.com/YuanYeYouTao/Yuki/pull/404)。

本轮运行资料只用于当前激活，放在当前用户正文之前，不保存全量、首次值或变化差量到公共历史。Work 状态 JSON 用 `<runtime_context>…</runtime_context>` 包裹，固定系统约束说明其中是程序提供的本轮系统运行资料、不是任何人的发言；保持原 user role、装配顺序和前后换行，空资料不展示。#305 的差量冻结实验和 #419 的旧方括号已由当前方案替代。显式新会话保留原私有观察、DAG、产物和事实。主要 PR：[#308](https://github.com/YuanYeYouTao/Yuki/pull/308)、[#311](https://github.com/YuanYeYouTao/Yuki/pull/311)、[#312](https://github.com/YuanYeYouTao/Yuki/pull/312)、[#316](https://github.com/YuanYeYouTao/Yuki/pull/316)、[#317](https://github.com/YuanYeYouTao/Yuki/pull/317)、[#419](https://github.com/YuanYeYouTao/Yuki/pull/419)、[#435](https://github.com/YuanYeYouTao/Yuki/pull/435)。

**Compact 已替代旧 Rollup、Work 摘要和普通聊天专用摘要链。** 完整请求可容纳时直接执行，自动整理只由真实输入容量不足触发；使用当前 Main 的模型、固定工具、Provider/Profile、思考与输出设置、并发槽位和原预算。公共检查点只覆盖获准公共历史，执行尾检查点归原 Work，保留配对工具、尚未观察的真实结果和后续原文。`/ai compact [重点]` 复用同一入口，只整理当前会话公共历史，沿原命令权限执行。主要 PR：[#423](https://github.com/YuanYeYouTao/Yuki/pull/423)、[#424](https://github.com/YuanYeYouTao/Yuki/pull/424)、[#425](https://github.com/YuanYeYouTao/Yuki/pull/425)。

冷恢复接入当前公共历史与本轮资料，并复用已持久化的付费响应；只有已派发、没有响应的调用继续保持未知。真实来源、generation 与隐私代次在发布处复核，缓存回收保留持久检查点，迟到结果不能覆盖已经采用的新检查点。`0119` 将有效旧公共检查点迁入既有 projection，并清退旧 Rollup 表、配置及等待字段；没有摘要的旧窗口继续在原 epoch 追加冻结历史，修复 renderer 升级冲突。详见[会话 Compact 合同](https://github.com/YuanYeYouTao/Yuki/blob/v3.9.0/docs/architecture/conversation-compact.md)。主要 PR：[#427](https://github.com/YuanYeYouTao/Yuki/pull/427)、[#429](https://github.com/YuanYeYouTao/Yuki/pull/429)、[#432](https://github.com/YuanYeYouTao/Yuki/pull/432)、[#433](https://github.com/YuanYeYouTao/Yuki/pull/433)。

历史、来源和身份在一致读快照中准备，SQLite writer 只复核与提交，不等待模型、网络或扫描历史。查询增加 canonical、事实与任务索引，移除重复扫描、无效缓存和准备阶段全局锁；SELF 修复跨批旧 WAL 快照，已知付费结果在写冲突后沿原记录继续发布。Embedding 队列在提交后更新，Rebuild 和 Memory 使用同一路径。优化不等于已经消除真实流量的延迟长尾。主要 PR：[#229](https://github.com/YuanYeYouTao/Yuki/pull/229)、[#236](https://github.com/YuanYeYouTao/Yuki/pull/236)、[#238](https://github.com/YuanYeYouTao/Yuki/pull/238)—[#245](https://github.com/YuanYeYouTao/Yuki/pull/245)、[#273](https://github.com/YuanYeYouTao/Yuki/pull/273)、[#298](https://github.com/YuanYeYouTao/Yuki/pull/298)、[#302](https://github.com/YuanYeYouTao/Yuki/pull/302)、[#324](https://github.com/YuanYeYouTao/Yuki/pull/324)、[#335](https://github.com/YuanYeYouTao/Yuki/pull/335)、[#394](https://github.com/YuanYeYouTao/Yuki/pull/394)、[#410](https://github.com/YuanYeYouTao/Yuki/pull/410)、[#429](https://github.com/YuanYeYouTao/Yuki/pull/429)。

### Memory、多模态与 Provider

长期事实按 fact ID 管理，同 key 的不同事实可以共存。删除单 active/key 槽位、旧关系好感与信任评分、自动关系打分、阶段语气、经验过时、强造争议、人工升格、腾位和自动注入等旧策略。自动提取只产生新 ASSERT；显式 `memory_change` 仍能按真实事实 ID 修改和删除。主动 `search_memory` 保留当前授权、时间条件与真实证据，人物姓名和提及复用现有身份还原链路，修复 issue #270 的无名主体与证据丢失。主要 PR：[#170](https://github.com/YuanYeYouTao/Yuki/pull/170)、[#176](https://github.com/YuanYeYouTao/Yuki/pull/176)、[#272](https://github.com/YuanYeYouTao/Yuki/pull/272)、[#273](https://github.com/YuanYeYouTao/Yuki/pull/273)、[#278](https://github.com/YuanYeYouTao/Yuki/pull/278)、[#328](https://github.com/YuanYeYouTao/Yuki/pull/328)。

提取、SELF 与 Dream 可以分别绑定 Profile，Rebuild 复用提取。删除换模型冻结 Rebuild、固定准备重试次数、重复恢复扫描、固定证据条数与无用诊断状态；真实批次来源、原执行和未处理部分继续保存。SELF 定时主入口及派生 Work 使用真实 execution Memory 来源，旧 generation 的失败运行不继续占用新有效范围。后台数据库异常不会让 Embedding 或 Dream 生命周期退出。主要 PR：[#282](https://github.com/YuanYeYouTao/Yuki/pull/282)、[#308](https://github.com/YuanYeYouTao/Yuki/pull/308)、[#322](https://github.com/YuanYeYouTao/Yuki/pull/322)、[#323](https://github.com/YuanYeYouTao/Yuki/pull/323)、[#332](https://github.com/YuanYeYouTao/Yuki/pull/332)、[#333](https://github.com/YuanYeYouTao/Yuki/pull/333)、[#336](https://github.com/YuanYeYouTao/Yuki/pull/336)、[#359](https://github.com/YuanYeYouTao/Yuki/pull/359)、[#360](https://github.com/YuanYeYouTao/Yuki/pull/360)、[#363](https://github.com/YuanYeYouTao/Yuki/pull/363)、[#370](https://github.com/YuanYeYouTao/Yuki/pull/370)、[#371](https://github.com/YuanYeYouTao/Yuki/pull/371)、[#395](https://github.com/YuanYeYouTao/Yuki/pull/395)。

当前、引用、历史附件、工作区和获准工具图片由原主模型读取，没有图片能力时如实保留未读状态。后台表情分类、SDK 显式视觉任务与 ASR 保留独立连接；语音保存完整识别正文并接纳全部附件，媒体文字不被误删。主要 PR：[#152](https://github.com/YuanYeYouTao/Yuki/pull/152)、[#247](https://github.com/YuanYeYouTao/Yuki/pull/247)、[#248](https://github.com/YuanYeYouTao/Yuki/pull/248)、[#338](https://github.com/YuanYeYouTao/Yuki/pull/338)、[#364](https://github.com/YuanYeYouTao/Yuki/pull/364)、[#365](https://github.com/YuanYeYouTao/Yuki/pull/365)。

系统约束、自我反思与 Dream 提示删去重复条款与注入，保留真实来源、时间、事实锚点及可以不改动或只完成部分整理的语义。主要 PR：[#430](https://github.com/YuanYeYouTao/Yuki/pull/430)，整合时的 Compact 用词修正见 [#429](https://github.com/YuanYeYouTao/Yuki/pull/429)。

连接显式选择 Chat Completions、Responses、Claude Messages、Gemini GenerateContent 及实际供应商方言，连接名称不代替协议。新安装默认开启模型搜索；Gemini Cloud Code 的独立原生搜索桥返回真实 grounding 证据，各连接按实际能力使用原生搜索，明确禁用仍有效。独立搜索不再被全局锁串行阻塞。新连接与未指定思考配置的 Profile 默认 medium，已有明确 low、high、关闭或空配置不会自动抬档。主要 PR：[#152](https://github.com/YuanYeYouTao/Yuki/pull/152)、[#170](https://github.com/YuanYeYouTao/Yuki/pull/170)、[#172](https://github.com/YuanYeYouTao/Yuki/pull/172)、[#253](https://github.com/YuanYeYouTao/Yuki/pull/253)、[#272](https://github.com/YuanYeYouTao/Yuki/pull/272)、[#309](https://github.com/YuanYeYouTao/Yuki/pull/309)、[#325](https://github.com/YuanYeYouTao/Yuki/pull/325)、[#362](https://github.com/YuanYeYouTao/Yuki/pull/362)。

结构化截断和纯文本 LENGTH 结果不再强行触发额外付费纠正或续写；截断工具调用不会执行，真实 Provider 暂停仍沿原检查点恢复。Claude 额外续跑、正文 DSML 转工具和无真实实现的声明回退退役。失败和迟到回执保留已知用量，逻辑调用与实际派发的 HTTP 请求分开计数；缺失明细和明确零不混为一谈。主要 PR：[#185](https://github.com/YuanYeYouTao/Yuki/pull/185)、[#187](https://github.com/YuanYeYouTao/Yuki/pull/187)、[#320](https://github.com/YuanYeYouTao/Yuki/pull/320)、[#398](https://github.com/YuanYeYouTao/Yuki/pull/398)、[#409](https://github.com/YuanYeYouTao/Yuki/pull/409)。

### 管理界面、插件、构建与退役

## English release notes

**Release date: October 15, 2026 (UTC+8).** Yuki 3.9.0 brings chat, autonomous activity, scheduled tasks and persistent Work onto the shared Main runtime. It replaces the old summary pipelines with Compact on the current Main model, preserves authorized calls through normal lifecycle settlement, and adds Linux arm64 support to the default direct release.

The product cutoff is main [`030917b1`](https://github.com/YuanYeYouTao/Yuki/commit/030917b1c994c9306bc1176663e989462153e222), merged as #437 at 05:41:22 on October 15 (UTC+8). The ledger below contains all **257 merged PRs** reachable from that commit and absent from `v3.8.4`. The release documentation PR is outside this frozen product count. Downloads are on the [3.9.0 Release](https://github.com/YuanYeYouTao/Yuki/releases/tag/v3.9.0); migration and configuration steps are in the [upgrade guide](https://github.com/YuanYeYouTao/Yuki/blob/v3.9.0/docs/upgrade-3.9.0.md).

### Shared Main, persistent work and child agents

Chat, SELF, schedules, plugin entrypoints and Work recovery use the same Main loop and frozen tool contract. The default direct image exposes the deployment's complete tool declarations without Monty. Code Mode remains an explicit build and configuration choice, using the same execution backend and authorization. Terminal tools are directly available.

Work retains its goal, original execution IDs, cumulative budget, private protocol and effect receipts across waits and restarts. Mandatory startup reports, delivery prerequisites for completion, repeated-result “no progress” decisions and fixed recovery or elapsed-time gates have been removed. Confirmed effects stay confirmed; unknown sends remain unknown and are reconciled through their original receipts. Terminal Work records are retained for late settlement.

Normal `complete`, `wait`, `need_input` and handoff decisions now settle after the already authorized response batch or Code program finishes. A `complete` followed by `send_message` in the same response can therefore deliver the message. A single capability rejection returns its own receipt so the program can handle it and continue with other authorized steps. Actual cancellation or failure of the current target, revoked sources and invalid leases still stop new effects from the old source. Recovery keeps original invocation keys, VM state, budgets and media pairing; first Work acceptance atomically records the original receipt and paid model accounting. See [#437](https://github.com/YuanYeYouTao/Yuki/pull/437).

Persistent child agents inherit Main's full fixed tools, core prompt and backend, with their own real source and permissions. Nested children attach to their actual parent Work and share the root budget. A real child question can resume a parent that can still consume it; a terminal parent leaves the question recorded and returns that fact. Existing children can be queried, messaged, cancelled or resumed by their original IDs without creating another parent Work. See [#426](https://github.com/YuanYeYouTao/Yuki/pull/426) and [#437](https://github.com/YuanYeYouTao/Yuki/pull/437).

### Common history, current runtime material and Compact

Each Conversation has one common public history. Speaker, personal preferences, entrypoint and read-scope changes no longer create separate historical views. Time display defaults to UTC+8; an explicitly configured schedule timezone remains part of that schedule. Private Work notes, protocol, DAG and artifacts retain their ownership, and current images no longer clear the whole public representation cache.

Current runtime material is prepared for the current activation and placed before its user text. The Work JSON uses `<runtime_context>…</runtime_context>`; the fixed system prompt explains that the block is program-supplied system runtime information rather than anyone's speech. The user role and assembly order stay intact. Empty blocks are omitted, and runtime material is not frozen into public history. See [#435](https://github.com/YuanYeYouTao/Yuki/pull/435).

**Compact replaces Rollup and the separate Work and ordinary-chat summary pipelines.** Automatic compaction happens when the complete request exceeds real input capacity. It uses the current Main model, fixed tools, Provider/Profile, thinking/output settings, concurrency slot and original budget. Public checkpoints cover authorized public history; private execution checkpoints belong to their original Work, preserving paired tools, unobserved receipts and the remaining original tail. `/ai compact [focus]` uses that same entrypoint for public history with the existing command permissions. See [#423–#427](https://github.com/YuanYeYouTao/Yuki/pull/423).

Recovery combines current public history and runtime material with the original task's evidence. Durable paid responses are reused; dispatched requests without a durable response remain unknown. Publication checks the real source, generation and privacy revision. Cache eviction keeps the durable checkpoint, and an older paid response cannot replace a newer adopted checkpoint. Migration `0119` carries valid old checkpoints into the existing projection and removes the retired Rollup storage and configuration. Empty legacy windows continue appending their frozen history in the same epoch after the renderer upgrade. See [#429](https://github.com/YuanYeYouTao/Yuki/pull/429), [#432](https://github.com/YuanYeYouTao/Yuki/pull/432) and the [Compact contract](https://github.com/YuanYeYouTao/Yuki/blob/v3.9.0/docs/architecture/conversation-compact.md).

SQLite preparation now keeps history scans, identity resolution and external work outside the writer. Canonical, fact and Work indexes reduce repeated scans; redundant caches, preparation locks and retry caps have been removed. Embedding scheduling happens after commit through the same Memory/Rebuild path. These changes do not establish a measured production latency improvement.

### Scheduling, memory, media and providers

Scheduled tasks activate Main with their original instructions and receipts. The old static delivery, typed DSL, separate model route and duplicate recovery/accounting paths are retired. Even a fixed-text reminder now uses the model and incurs model cost. SDK automation creation requires a stable explicit `request_id`, preserving retry identity while allowing separate tasks. Group auto-replies and autonomous wakeups have independent global and per-group switches; consecutive ordinary inputs can share one pending opportunity, and existing Work keeps its original inputs. Merged forwards are read explicitly by the outer message's internal event ID, returning the first level rather than recursively expanding media and nested forwards.

Long-term memory uses fact IDs and permits distinct facts with the same key. Automatic extraction adds assertions; explicit `memory_change` can still change or remove real facts. Relationship scores, trust/affinity policies, automatic injection and forced controversy have been retired. Extraction, SELF and Dream can use separate Profiles while keeping their original evidence and identity. System, reflection and Dream prompts remove repeated instructions and retain source, time, explicit anchors and partial-result semantics; [#430](https://github.com/YuanYeYouTao/Yuki/pull/430) supplied the prompt cleanup, with the Compact wording correction in #429.

Main reads authorized current, quoted, historical, workspace and tool images through its own model. ASR retains complete recognized text and all audio attachments. Provider connections explicitly select Chat Completions, Responses, Claude Messages or Gemini GenerateContent and their dialects; native search returns real grounding where supported. New installations enable model search by default while preserving explicit disablement and the connection's actual capabilities. New connections and Profiles with unspecified thinking use medium, preserving existing explicit choices. Truncated text no longer triggers another paid correction request, and truncated tool calls are not executed. Usage keeps known values from failed or late responses and distinguishes missing fields from explicit zero.

### Installation, plugins and retired components

The default direct release has one versioned image index for `linux/amd64` and `linux/arm64`. Both installers detect the Docker Engine architecture; the static WebUI is built on the build host. Compose selects the host variant, and existing deployments must remove an old amd64 platform pin as described in the upgrade guide. The Release workflow pulls and verifies each published platform in a source-free deployment, including identity, migration, health and persisted data after recreation, before copying the full index to `latest`. Existing arm64 execution evidence uses QEMU; native ARM hardware acceptance has not been recorded. Older release assets remain unchanged. See [#431](https://github.com/YuanYeYouTao/Yuki/pull/431), fixing [#288](https://github.com/YuanYeYouTao/Yuki/issues/288), and its integration in #429.

The release baseline is **schema `0119`, Plugin API `3.5` with exact matching, Main manifest `19`, context layout `2`, send schema `2`, and optional Code API `yuki.codemode.api.v2`**. Source execution requires Python 3.12. Old Code stop records and incompatible snapshots preserve their actual receipts rather than reopening a stopped VM. Back up the database and referenced files together, migrate from the real revision without `stamp`, and retain new post-upgrade facts when rolling code back.

The WebUI provides shared configuration, chat, traces, usage, tool receipts, workspaces and terminals; it is disabled by default. Its replacement by a multi-client design is a future major-version plan. Plugins need the current API contract and approval; SDK schedules also need the explicit request ID. NapCat, MCP, Genie speech output and old administrator-only tools have been retired, with SnowLuma as the bundled gateway and management through the existing WebUI, CLI and `/ai` paths. Existing external configuration is not overwritten. Version 3.9.0 uses **AGPL-3.0-only**; historical assets retain their bundled licenses and third-party notices.
