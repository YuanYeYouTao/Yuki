# Yuki 3.9.0 发布说明（草案）

<!-- release-baseline: version=3.9.0 schema=0097 -->

**3.9.0 是当前开发基线，尚未正式发布。** 正式下载仍为 [3.8.4](https://github.com/YuanYeYouTao/Yuki/releases/tag/v3.8.4)。本草案覆盖 `v3.8.4` 标签提交 `9c20ede` 之后、截至主线 `16b5c7b8`（2026-10-07，Asia/Taipei）的 **102 个已合并 PR**。开发提交镜像的上线记录与正式 Release 分开核对；源码版本号不代表已有 `:3.9.0` 发行镜像。

## 3.9.0 的主要变化

- **本轮本地变更：彻底退出 Genie 语音输出。** 删除合成、声线/偏好、主工具 voice 参数、SDK/管理入口、配置、Worker/转换器和双镜像发布依赖。Plugin API 为 3.2，主合同为 13，send schema 为 2，迁移 head 为 `0097`。ASR、历史语音/转写、原 Work/发送回执及普通媒体保留。旧执行先核原身份，已确认不重发、未知不转失败；语音事实和被引用 WAV 须在部署前冷备。本项尚未合并、发布或部署，不计入下文已合并 PR 数量。

- **完整管理 WebUI。** 聊天时间线关联真实入站、发出消息及执行轮次；可查看模型请求、工具调用、用量、工作区、终端和媒体。模型连接、任务路由、配置与管理操作沿共享控制面保存。查询按内部事件/轮次索引分页，管理身份和写入权限由服务端核验。WebUI 默认关闭，3.8.4 正式资产不包含此界面。主要 PR：[#153](https://github.com/YuanYeYouTao/Yuki/pull/153)—[#166](https://github.com/YuanYeYouTao/Yuki/pull/166)、[#175](https://github.com/YuanYeYouTao/Yuki/pull/175)、[#252](https://github.com/YuanYeYouTao/Yuki/pull/252)。

- **统一主 Agent 与持久运行时。** 普通聊天、主动触发、插件唤醒、自动化、子任务与 Work 续跑复用同一个 `YukiRuntime`。主 Agent 使用固定工具声明，执行时核验权限与预算；历史保存当轮真正提交的动态快照。切换模型连接只影响后续激活，原 Work ID、预算、工具效果及发送回执继续保留。主要 PR：[#214](https://github.com/YuanYeYouTao/Yuki/pull/214)、[#218](https://github.com/YuanYeYouTao/Yuki/pull/218)、[#228](https://github.com/YuanYeYouTao/Yuki/pull/228)。

- **长任务压缩、续跑与用户介入。** 增加持久上下文整理和协议对象管理，按实际模型输入、工具声明及私有续跑状态计算容量。整理水位是软目标，完整请求能装入时不因经验阈值暂停；正在进行的 Work 继续纳入新聊天与用户指示。新任务可配置累计预算，旧有限预算不重置。汇报利用现有发送工具及结果机会，不强制闲聊逐阶段报告。主要 PR：[#215](https://github.com/YuanYeYouTao/Yuki/pull/215)、[#216](https://github.com/YuanYeYouTao/Yuki/pull/216)、[#220](https://github.com/YuanYeYouTao/Yuki/pull/220)—[#229](https://github.com/YuanYeYouTao/Yuki/pull/229)、[#254](https://github.com/YuanYeYouTao/Yuki/pull/254)、[#255](https://github.com/YuanYeYouTao/Yuki/pull/255)。

- **修复执行归属与恢复反馈。** 终端工具成功返回与进程成功退出分开说明，退出码、未完成状态和局部修改事实保留到原回执。已执行、确定未派发和结果未知得到不同反馈；后台进程、任务自身脚本与原 Work 的归属核对更完整，恢复原执行而不创建第二次运行。未知发送、原生工具效果或控制操作先核原回执，不因超时自动重发。主要 PR：[#182](https://github.com/YuanYeYouTao/Yuki/pull/182)、[#242](https://github.com/YuanYeYouTao/Yuki/pull/242)、[#255](https://github.com/YuanYeYouTao/Yuki/pull/255)、[#258](https://github.com/YuanYeYouTao/Yuki/pull/258)。

- **群聊持续接话。** 真人邀请和已有互动的续聊进入普通消息路径，复用同一媒体准备和 Work 协调；持续接话不再每轮额外请求 Jev。原内部事件接纳去重，局部参与状态和实际发送反馈保留来源；自主加入仍沿 SELF 与既有开关。参与意愿变化不会重写旧历史，也不保证每次机会都会发言。主要 PR：[#150](https://github.com/YuanYeYouTao/Yuki/pull/150)、[#151](https://github.com/YuanYeYouTao/Yuki/pull/151)、[#230](https://github.com/YuanYeYouTao/Yuki/pull/230)。

- **记忆按需自主检索。** 主 Agent 通过 `search_memory` 主动查找需要的记忆，明确区分查询列表、暴露证据和真正使用。截断、预算限制、不完整结果与 Embedding 降级原因对调用者可见；检索未命中不伪装成事实不存在。删除无有效工作时的重复记忆重建写入。主要 PR：[#170](https://github.com/YuanYeYouTao/Yuki/pull/170)、[#176](https://github.com/YuanYeYouTao/Yuki/pull/176)、[#203](https://github.com/YuanYeYouTao/Yuki/pull/203)、[#244](https://github.com/YuanYeYouTao/Yuki/pull/244)。

- **当前、历史与工作区图片共用原生多模态。** 主 Agent 自选历史附件、工作区文件或获准工具图片后，由原主模型读取像素，复用当前/引用图片的协议编码；不再隐式调用 Qwen 为历史图片生成视觉摘要。工具回执、图片顺序、来源授权及原 Work 检查点一起保存；没有图片能力时明确未读。后台表情分类、SDK 显式视觉任务与 ASR 仍是独立消费者。修复投影重放再次选中当前触发消息的问题。主要 PR：[#152](https://github.com/YuanYeYouTao/Yuki/pull/152)、[#247](https://github.com/YuanYeYouTao/Yuki/pull/247)、[#248](https://github.com/YuanYeYouTao/Yuki/pull/248)。

- **多 Provider、热配置与默认联网。** 支持 Chat Completions、Responses、Claude Messages、Gemini GenerateContent 及现有供应商方言。新安装未显式设置联网模式时默认开启模型搜索；显式禁用和既有 Profile 选择保持有效，模型仍须具备真实搜索能力。Gemini 搜索桥在独立搜索请求中使用 Google Search，与主调用的函数工具分开；可用网页正文提取最多三路并行。主要 PR：[#152](https://github.com/YuanYeYouTao/Yuki/pull/152)、[#170](https://github.com/YuanYeYouTao/Yuki/pull/170)、[#172](https://github.com/YuanYeYouTao/Yuki/pull/172)、[#202](https://github.com/YuanYeYouTao/Yuki/pull/202)、[#245](https://github.com/YuanYeYouTao/Yuki/pull/245)、[#253](https://github.com/YuanYeYouTao/Yuki/pull/253)。

- **可纠正的工具错误。** 参数拒绝向模型提供安全字段路径、类别与期望类型；不同 Provider 按自身协议表达已知失败。Gemini 确认未执行的错误函数调用最多给两次纠正机会，仍计入原请求预算。原生工具已经派发、结果未知或检查点保存失败时不取得重跑资格。主要 PR：[#251](https://github.com/YuanYeYouTao/Yuki/pull/251)、[#255](https://github.com/YuanYeYouTao/Yuki/pull/255)。

- **减少回复准备的数据库争用与重复读取。** 来源历史与指纹在只读快照中准备，writer 只复核版本和提交；移除可丢诊断在模型返回路径上的写入等待，缩短参与对账、Work 存储及回执整理的事务。已认证入站复用可信关系，冻结历史只补读需要的正文；空恢复轮询和来源查询使用候选/部分索引。模型并发 admission、锁队列、Provider 耗时和发送确认分别观测，不把阶段差额称作锁等待。这些优化不表示换页压力或上游延迟已消失。主要 PR：[#213](https://github.com/YuanYeYouTao/Yuki/pull/213)、[#229](https://github.com/YuanYeYouTao/Yuki/pull/229)、[#232](https://github.com/YuanYeYouTao/Yuki/pull/232)、[#236](https://github.com/YuanYeYouTao/Yuki/pull/236)、[#238](https://github.com/YuanYeYouTao/Yuki/pull/238)—[#245](https://github.com/YuanYeYouTao/Yuki/pull/245)。

- **完全退役现有 MCP。** 删除连接生命周期、工具发现、配置、管理 WebUI、SDK facade、自动化桥及 MCP 依赖。通用工具正文、图片、脱敏、来源证据和 Work 回执迁入 `tool_results/`，原数据与读取授权保留。Plugin API 升至 **3.1**，插件需适配并重新批准；网易云 MCP 插件退役，普通插件 HTTP、自有工具及 QQ 音乐卡片发送保留。旧管理授权中的 MCP 权限须显式撤去，不能仅删环境变量。主要 PR：[#259](https://github.com/YuanYeYouTao/Yuki/pull/259)、[#260](https://github.com/YuanYeYouTao/Yuki/pull/260)。

网关快速重连、健康检查与首次启群等修复也包含在本版。开发中的 Code Mode/Pi 分支尚未合入本截止提交，不列作 3.9.0 已有功能。完整行为边界见[架构索引](../architecture/README.md)。

## 缓存与用量

固定工具合同、当轮历史快照和原协议续跑状态减少不必要的请求前缀变化。Claude 增加跨轮前缀缓存与 5 分钟/1 小时写入用量记录；失败请求保留已知 usage，逻辑模型调用与实际派发的 HTTP 请求分开计数。总量、明细缺失和零用量不混为一谈。

缓存数据按 Provider、日期、场景和计量覆盖分别报告；加权比例为 `Σ已知 cached input / Σ这些请求的 input`，缺少缓存字段的请求保持未知。下表为公开记录中的历史样本，不是本截止提交或 MCP 退役后的最新线上命中率。

| 样本与日期（Asia/Taipei） | 模型 / 场景 | 缓存计量覆盖 | 已知命中输入 / 对应输入 token | 输入加权比例 |
| --- | --- | --- | ---: | ---: |
| [10-01 核查报告](../operations/provider-compaction-audit-2026-10-01.md)，自然群聊一个回复轮 | `gemini-3.8-flash`，同链三次请求 | 3/3 | 96,464 / 106,532 | **90.55%** |
| [10-03 多场景手工实验](../operations/semantic-continuation-2026-10-03.md#手工缓存样本) | `gemini-3.8-flash`，续聊、Work 切换、恢复、压缩 | 7/13，另 6 次未知 | 121,264 / 163,332 | **74.24%** |
| 同一多场景实验 | `deepseek-flash` / Responses，含冷轮和独立摘要 | 13/13，含 1 次明确零缓存 | 222,976 / 316,442 | **70.46%** |
| [10-03 累积聊天手工实验](../operations/work-context-cache-experiment-2026-10-03.md)，03:40—03:41 | `deepseek-flash` / Responses，一次预热加八次续接 | 9/9 | 178,560 / 187,745 | **95.11%** |

最后一组八次热续接单独为 **99.02%**（165,760 / 167,395 token），完整九次的 95.11% 保留首请求，不能只取热轮宣传整体命中率。实验使用合成公共前缀与真实 Provider 请求，不读取生产聊天或向 QQ 发消息；多场景实验的 DeepSeek 有一项未发布要求的 context note，HTTP 成功与缓存计量不等于任务能力全部通过。

Gemini 多场景的全部已报输入为 319,485 token，表中分母只包含缓存字段已知的七次请求，不能把另外六次当零或推算精确总体命中率。[脱敏计量文件](../operations/evidence/semantic-continuation-cache-20261003.json)保留完整覆盖口径。各组模型、时间、场景和合同不同，不是 Provider 优劣或修改前后提速的 A/B；缓存命中也不能证明回复时延正常。

## 版本与升级边界

| 项目 | 本开发基线 |
| --- | --- |
| 应用源码版本 | 3.9.0；正式发行仍为 3.8.4 |
| 数据库迁移 | 当前单一 head `0097`；3.8.4 正式镜像随包为 `0072` |
| Plugin API | 3.2；Genie-TTS Worker 已退出当前源码与发行流程 |
| 部署 | 正式发行尚未执行；开发部署按实际提交镜像和运维记录核对 |

`0073`—`0085` 补齐控制回执、执行与用量索引、拆分发送计划、Claude 缓存写入和来源失效覆盖；`0086`—`0089` 保存工具效果、可配置累计预算、私有协议对象与有序来源；`0090`—`0095` 增加维护/读取索引和普通消息接纳去重；`0096` 核验形状与依赖后仅删除 `mcp_server_states`、`mcp_tool_cache` 两张派生表。旧调用、旧发送计划、未知用量和未知效果不靠迁移推断或重跑。完整迁移分组、配置、备份与回退边界见 [3.9.0 升级草案](../upgrade-3.9.0.md)。

`0097` 在完整形状和依赖预检后，精确清退配置键与四张 Speech 专属表；未知依赖或仍在 queued/generating 的旧生成会拒绝升级。终态记录仍有真实事实，升级前必须核通用回执、文件引用并验证一致私有冷备，不能按缓存删除。

升级至 `0097` 后不能直接换回旧 head 镜像；优先在新 schema 向前修补。备份需同时覆盖数据库、配置、工具正文、媒体、被引用语音、私有协议对象及持久环境回执，旧备份不能覆盖升级后产生的事实。各功能的离线回归、真实模型重放、自然 QQ 验收与部署记录分别核对，不将其中一种验证当作其他层的通过。
