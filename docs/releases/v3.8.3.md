# Yuki 3.8.3

<!-- release-baseline: version=3.8.3 schema=0063 -->

3.8.3 汇总自 [3.8.2](https://github.com/YuanYeYouTao/Yuki-QQbot/releases/tag/v3.8.2) 发布以来合入 `main` 的全部 PR。重点是持久工作与恢复、统一主 Agent、长会话 Rollup 保护，以及 Self Reflection 的持久周期和诊断。本版发布源码和部署包；**发布本身不会自动更新现有生产服务器**。

## 主要变化

- 工作任务可持久续跑，保留原执行 ID、共享预算、进度、交付回执与权限快照；Bot 重启、异常、聊天插入和 SQLite 竞争下的恢复路径得到加固。子任务与自动化也回到同一主 Agent 执行链。
- Rollup 在语义压缩期间保护原始来源，分离输入/输出预算并改善被聊天打断后的唤醒，避免长群会话旁路堆积。
- Self Reflection 以持久周期、分段回执和 Responses 结构化输出工作；增加诊断、快照生命周期、长周期 ingress 更新和独立 drain 控制。该改动不代表自省结果无需人工核查。
- 固定主 Agent 工具合同，执行处继续校验权限；删除废弃自动化管理入口及麦当劳 MCP 预设。联网不再按消息内容隐式切换 Provider。
- 修复附件渲染权限与历史读取、群名刷新、数据库写事务跨网关探测等问题。
