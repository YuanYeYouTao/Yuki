# Yuki 3.8.3

<!-- release-baseline: version=3.8.3 schema=0061 -->

状态：开发基线，尚未发布正式标签或发行资产。本次基线更新不部署生产环境。

## 本版范围

- 主 Agent 使用统一入口和部署级固定工具合同；普通续跑追加历史，合同变化显式换链。
- 持久工作任务和子 Agent 支持分段、等待与恢复，保留预算、执行 ID 和交付回执。
- 自动化和插件生成接回主执行链，避免旧预算与简化执行路径截断任务。
- Self Reflection 使用持久周期、分段回执和独立 drain 开关。
- 整理公共执行提示词及工具说明，移除失效管理入口、旧工具动态加载后备路径和麦当劳 MCP 预设。RSS 与持久工作环境保留。
- 发布检查对齐应用版本及实际迁移 head，普通 PR 也提前检查版本和文档。

## 发布基线

| 项目 | 目标 |
| --- | --- |
| 应用版本 | 3.8.3 |

| Plugin API | 2.0 |

数据库版本从随包迁移图取得，不由应用版本推算。此次没有新增或改写迁移。
3.8.2 发布包对应 0055；其后 0056–0061 覆盖任务、子 Agent、内部事件关联、恢复与交付、自动化预算及自省周期。

现有测试中的动态加载假设已改为固定声明，工具权限仍由执行处校验。缓存实际命中取决于 Provider，本版不承诺固定命中率。

配置及升级步骤见 [3.8.3 升级指南](../upgrade-3.8.3.md)。正式发布前，不把预期镜像标签或部署包当作已可下载资源。
