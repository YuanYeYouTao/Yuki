# Yuki 3.8.2

产品 3.8.2，schema 0055，Plugin API 2.0，Genie-TTS Worker 1.9.0。
本版包含已合并的主 Agent、语音识别、社交修复及持久工作环境。

## 本次合并范围

- 配置向导：保留交互配置、校验和配置备份，移除自动停服、数据库升级、部署文件替换及网关切换。
  已有部署按升级指南操作，避免临时配置工具承担完整升级流程。

- 主 Agent：统一聊天、插件、定时自动化和续跑入口，完整固定工具声明与有界历史投影，
  保留委托和发送权限；全局 short_state 与持久文件分开管理。
- 社交：按原消息账号撤回，按群可达性查询成员，多绑定歧义拒绝，结构化提及，
  自动化戳人授权校验，以及有真实来源约束的网关历史读取。
- 语音识别：复用 Qwen，覆盖私聊、群聊和引用语音，转写进入历史、搜索和 Rollup。
- 工作环境：常驻 gVisor + execd、全局 2 GiB 家目录、交互终端、后台任务接管、
  pip/npm 依赖、apt 安装和检查点、内部服务、文件发布及旧 artifact 兼容。
- 运行恢复：释放空闲事件载荷和会话资源，持久回执、任务幂等与重连恢复；
  文件和工具能力采用一致声明，运行状态及权限不改变发送的 schema。
- Memory P1：一小时/12事件/8000字符普通批次，首次自动写入价值门槛，历史共同群读取，
  attribution 未评估与未使用分离；显式修改仍即时执行。
- 自省：canonical 会话配置、异常隔离、持久结果恢复、可见证据约束、逐片段来源绑定。
- Dream：输入不静默截断，有界修复、意义优先的绝对输出预算、失败公平调度；回滚拒绝
  指向其他事实的证据或关系编号。
- 检索：当前主题优先、跨目标排序、最多四条自动预取；严格日期、明确目标、统一意图、
  真实会话查询回执、完整事实前缀与截断说明，弱候选不标为已核实事实。
- Harness：固定查证说明及证据状态；区分工具可用、调用、结果暴露与最终使用；所有
  生成任务至少 low，保留更高配置，不改变人格文件或创建独立短上下文。
- 审计：SELF 出站、工具回执与规范化来源口径一致；保留工具证据版本；争议状态不再误报。

## 已知限制与发布判断

开发探测仍出现自省将旧回复中的主张写成确定经历，逐段引用并不证明语义正确。
medium/8192 组合探测在进行人工核对，不是生产默认设置。完整历史独立60/30样本与
相关性指标尚未完成，不能宣称已达到原效果门槛。

用户已授权改为按阻断级风险收口发布；发布检查和残余风险须如实记录，不把测试通过
等同于语义质量通过。是否上线以最终发布验收记录为准。

旧0048迁移在事务内切换外键无效，可能导致重建表时丢失状态、关系和证据。
已用历史函数复现，并在隔离副本验证恢复；这些实验不是升级脚本，不会自动恢复生产
数据。线上仍可能有历史审计错误/警告，必须单独核对和制定恢复范围。
