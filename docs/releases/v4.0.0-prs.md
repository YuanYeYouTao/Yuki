Earlier-created PR #420 is included because it merged within this ancestry.

Authors below are GitHub PR authors, and merge links identify actual merge commits. Documentation-only work is marked explicitly. This release-preparation PR, unmerged proposals, PRs in other repositories and benchmark execution code are outside the 37-PR product ledger.
