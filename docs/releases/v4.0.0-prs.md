## 范围与核对方法 / Scope and method

核对日期：2026-11-11。范围是正式 `v3.9.0` 的实际提交 [`12de953eb34bab084b6aeb6e4e909f885db17921`](https://github.com/YuanYeYouTao/Yuki/commit/12de953eb34bab084b6aeb6e4e909f885db17921) 之后、到 [#610](https://github.com/YuanYeYouTao/Yuki/pull/610) 为止的全部已合并 PR，共 **146 个**：截至 [`81f10229`](https://github.com/YuanYeYouTao/Yuki/commit/81f102291b737368d00b162a79774c272dcfeb16)（#558）的 101 个按 2026-11-02 的方法核对（Git 完整祖先差集与全部 closed PR 的合并提交求交，不按创建时间、PR 编号或单页截断；嵌套整合的 #494/#497 及较早创建的 #420 保留独立作者与合并记录），#559 至 #610 的 45 个按 GitHub 已合并 PR 列表逐项补入（不含发布本身的文档 PR #608）。

Audited on 2026-11-11: every merged PR after the actual v3.9.0 tag commit through [#610](https://github.com/YuanYeYouTao/Yuki/pull/610), **146 in total**. The 101 through `81f10229` (#558) were audited on 2026-11-02 by intersecting the complete Git ancestor difference with the merge commits of all closed PRs, without filtering by creation date, PR number or page; nested integrations #494/#497 and the earlier-created #420 keep their own author and merge record. The 45 from #559 to #610 (without #608, the release's own documentation) were added from GitHub's merged-PR list.

文档、测试、实际实现与已被后续方案替代的变更分别说明。发布 4.0.0 自身的文档 PR 不递归计入。未合并计划、其他仓库（包括 Yuki Desktop）的 PR 与 benchmark 执行代码不计入；后者仍沿原 benchmark 分支归属。这里记录源码合并，不代替 Release、安装包、部署或真人验收。

Documentation, tests, implementation and superseded behavior are identified separately. The documentation PR that publishes 4.0.0 is not counted. Other repositories (including Yuki Desktop), unmerged plans and benchmark execution code are excluded. Merged source is distinct from publication, installation, deployment and human acceptance.
