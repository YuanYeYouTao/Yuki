4.0 把 Yuki 从以 QQ 为中心的 Bot，推进为同一个长期存在的 Agent：QQ、Telegram、飞书、Lark、个人客户端和 ACP 共用人物身份、Main、Memory、工具与持久任务。Yuki 可以在服务器的持久环境工作，也可以经本人授权的连接器使用电脑上的 Shell、文件和已有编码 Agent。模型、管理权限与桌面端有了完整的配套入口。

**本文是待发布说明，不表示 4.0.0 已发行。** 2026-11-02 核对的范围是正式 [v3.9.0](https://github.com/YuanYeYouTao/Yuki/releases/tag/v3.9.0) 的实际提交 `12de953eb34bab084b6aeb6e4e909f885db17921` 之后，到 main [`81f102291b737368d00b162a79774c272dcfeb16`](https://github.com/YuanYeYouTao/Yuki/commit/81f102291b737368d00b162a79774c272dcfeb16)（#558）：**101 个已合并 PR、446 个提交**。本文末尾直接列出全部 PR，详细归属另见贡献目录；本次文档更新自身不递归计入。正式下载目前仍为 3.9.0。

## 多个平台，同一个人物

QQ、Telegram、飞书与 Lark 沿公共身份、消息、媒体和发送服务接入。飞书/Lark 使用企业自建应用的长连接，无需公网回调，支持私聊、群聊、话题、提及、引用及图片/文件。一个 Person 可以关联多个平台账号，也可以没有账号；账号转交只改变未来归属，原消息、记忆、Work 与执行回执保留原人物和来源。关联账号不会把不同入口拼成同一段历史。

原生提及保留原句位置、当时名字与真实账号快照。普通 `@名字` 在目标会话解析，精确账号可显式指定；引用、附件和后台表情沿原会话及原接收/发送账号处理。某个平台入站受阻也不再让整个 Bot 退出。主要 PR：[#458](https://github.com/YuanYeYouTao/Yuki/pull/458)、[#474](https://github.com/YuanYeYouTao/Yuki/pull/474)、[#482](https://github.com/YuanYeYouTao/Yuki/pull/482)、[#484](https://github.com/YuanYeYouTao/Yuki/pull/484)、[#486](https://github.com/YuanYeYouTao/Yuki/pull/486)、[#491](https://github.com/YuanYeYouTao/Yuki/pull/491)、[#525](https://github.com/YuanYeYouTao/Yuki/pull/525)、[#526](https://github.com/YuanYeYouTao/Yuki/pull/526)、[#531](https://github.com/YuanYeYouTao/Yuki/pull/531)。

## 桌面端和本机电脑

[Yuki Desktop](https://github.com/Institute-of-Agent-Life/Yuki-Desktop) 已有独立 Windows、macOS、Linux beta 发行。配套源码支持配对、聊天、附件与富媒体、Work、文件、Memory、自动化、Computer、模型配置与用量；可连接已有 Yuki，也可通过 Docker 部署本机 Bot。两仓分别发版，更新桌面软件不会升级远端 Bot。

本机操作统一沿 `yuki-agent-connector` 的主动 WSS 连接、原设备身份和 journal。明确开启完整访问后，Yuki 按连接器 OS 账号权限使用 Shell、文件与已安装程序，不要求先配置编码 Agent。可选 Codex、Claude Code 和 ACP 使用原生登录与原会话；发现安装、传输在线、原生就绪与实际完成分别报告。重复 LocalExecutor 已退役，旧回执保留原事实。

连接器 **0.4.2 / 协议 4** 修复 Windows 原生进程控制台弹窗和安装锁偏移。桌面管理的连接器随 Desktop 启动、真正退出时停止，关闭窗口留在托盘仍连接；不注册登录自启。接管已有独立安装保留 device、instance、凭据和 journal。主要 PR：[#497](https://github.com/YuanYeYouTao/Yuki/pull/497)、[#510](https://github.com/YuanYeYouTao/Yuki/pull/510)、[#515](https://github.com/YuanYeYouTao/Yuki/pull/515)、[#517](https://github.com/YuanYeYouTao/Yuki/pull/517)、[#518](https://github.com/YuanYeYouTao/Yuki/pull/518)、[#520](https://github.com/YuanYeYouTao/Yuki/pull/520)、[#530](https://github.com/YuanYeYouTao/Yuki/pull/530)、[#533](https://github.com/YuanYeYouTao/Yuki/pull/533)、[#535](https://github.com/YuanYeYouTao/Yuki/pull/535)、[#536](https://github.com/YuanYeYouTao/Yuki/pull/536)、[#556](https://github.com/YuanYeYouTao/Yuki/pull/556)、[#557](https://github.com/YuanYeYouTao/Yuki/pull/557)。桌面仓库 PR 单独归属，不混入本文 101 项。

Tailscale 为可选私有网络方式：两端分别安装并登录，服务器宿主机配置 Serve HTTPS。桌面提供引导，不捆绑 Tailscale 或替用户处理账户认证。客户端与 Connector 各自保存地址；换线保留设备身份和原配对，不自动同步两边。原 SSH/VPN 仍可使用。见[接入指南](https://github.com/YuanYeYouTao/Yuki/blob/main/docs/operations/tailscale-connection.zh-CN.md)。主要 PR：[#540](https://github.com/YuanYeYouTao/Yuki/pull/540)、[#542](https://github.com/YuanYeYouTao/Yuki/pull/542)。

## 模型配置与真实用量

部署和桌面管理共用 Provider 预设、协议与用途能力元数据。聊天、Memory、SELF 等用途显式选择 Profile，Embedding、视觉、ASR 与搜索进入已有模型 bundle。密钥留在私有 sidecar 或声明的环境来源，不随配置读取返回。连接支持模型 ID 发现及已保存/草稿测试；实际测试会调用上游，可能产生费用。

明确关闭的连接与搜索模式不会暗中切换供应商。辅助连接变更需要重启时如实返回 `restart`，聊天模型沿原热应用路径；更换 Embedding 建立不可变 profile，保旧向量。旧配置可通过一次性离线命令迁移真实有效来源，沿原 revision/CAS 保存，保留明确关闭与原已付请求。见[模型配置升级](https://github.com/YuanYeYouTao/Yuki/blob/main/docs/upgrade-model-config-20261031.md)。主要 PR：[#548](https://github.com/YuanYeYouTao/Yuki/pull/548)、[#549](https://github.com/YuanYeYouTao/Yuki/pull/549)、[#550](https://github.com/YuanYeYouTao/Yuki/pull/550)、[#551](https://github.com/YuanYeYouTao/Yuki/pull/551)、[#552](https://github.com/YuanYeYouTao/Yuki/pull/552)。

用量按原调用账本、时间窗口、时区及实际记录的供应商/模型汇总。改名或换配置不会重标旧请求；已知输入、输出、缓存 token 与缺失计量分开，缺失不伪作零，不凭空估价。桌面将常用概览与内部诊断分开。主要 PR：[#551](https://github.com/YuanYeYouTao/Yuki/pull/551)、[#554](https://github.com/YuanYeYouTao/Yuki/pull/554)；桌面呈现属于其独立 PR #36。

## Person 超级管理员与单一人格

超级管理员资格直接属于 Person，改名、换平台、解绑不丢资格，账号转交不携带资格，普通 `/ai link` 配对不授予管理权限。Person 超管通过原 Desktop 凭据使用管理 API，非超管继续使用获准的个人功能。

**独立 character owner 角色已删除。** 共享名称、头像、SOUL、模型管理和共享服务器 Computer 按当前 Person 超管核验；历史 owner 行与回执保留，不自动升权。可信本地 setup 由原显式请求授予部署者 Person 超管；存量远端管理员由独立 operator 核对后显式授予。主要 PR：[#476](https://github.com/YuanYeYouTao/Yuki/pull/476)、[#545](https://github.com/YuanYeYouTao/Yuki/pull/545)、[#546](https://github.com/YuanYeYouTao/Yuki/pull/546)、[#547](https://github.com/YuanYeYouTao/Yuki/pull/547)；[#523](https://github.com/YuanYeYouTao/Yuki/pull/523) 的中间放宽方案已由 [#545](https://github.com/YuanYeYouTao/Yuki/pull/545) 替代。

用户人格只来自选定 `SOUL.md`，名称来自当前资料，技术规则独立装配。空正文合法，新激活采用新值，历史、已提交请求、主体身份与固定工具不改。旧双人格文件退出，已有部署明确整理旧内容与挂载。主要 PR：[#490](https://github.com/YuanYeYouTao/Yuki/pull/490)、[#545](https://github.com/YuanYeYouTao/Yuki/pull/545)、[#555](https://github.com/YuanYeYouTao/Yuki/pull/555)。

## 持久工作、历史和工具

Main、SELF、自动化与子任务共用 Work 执行链，持久保存目标、父子关系、累计预算、模型请求和外部效果。确认丢失先查原 request/run；已接纳等待和完成沿原状态收尾，子任务问题回到原工作。Compact 复用公共检查点，未被模型观察的工具结果留在原执行尾部。主要 PR：[#470](https://github.com/YuanYeYouTao/Yuki/pull/470)、[#500](https://github.com/YuanYeYouTao/Yuki/pull/500)、[#502](https://github.com/YuanYeYouTao/Yuki/pull/502)、[#504](https://github.com/YuanYeYouTao/Yuki/pull/504)、[#511](https://github.com/YuanYeYouTao/Yuki/pull/511)、[#533](https://github.com/YuanYeYouTao/Yuki/pull/533)、[#544](https://github.com/YuanYeYouTao/Yuki/pull/544)、[#555](https://github.com/YuanYeYouTao/Yuki/pull/555)。

普通文件、Python、系统包和交互程序由持久终端处理。统一 `send` 交付文字或文件，内部冻结版本，删除模型“先发布再发送”的额外步骤和永久中转副本。工具正文直接进入有效结果预算，超长内容附准确的 Artifact 续读参数。人物/空间发现与会话发现分别用 `find_contacts`、`find_conversations`。主要 PR：[#463](https://github.com/YuanYeYouTao/Yuki/pull/463)、[#495](https://github.com/YuanYeYouTao/Yuki/pull/495)、[#539](https://github.com/YuanYeYouTao/Yuki/pull/539)。

显式历史查询共用 recent/search/around 与唯一索引，支持平台、群私聊、作者、日期、媒体和来源分页。`/ai new` 只重开当前上下文，当前获准的永久账本仍可查询；结果保留原 Conversation、作者与事件。主要 PR：[#489](https://github.com/YuanYeYouTao/Yuki/pull/489)、[#492](https://github.com/YuanYeYouTao/Yuki/pull/492)、[#494](https://github.com/YuanYeYouTao/Yuki/pull/494)。
