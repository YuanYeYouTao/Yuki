# Yuki 4.0.0 release notes (unreleased)

<!-- release-baseline: version=4.0.0 schema=0155 -->

[中文](https://github.com/YuanYeYouTao/Yuki/blob/main/docs/releases/v4.0.0.md) · [Upgrade guide](https://github.com/YuanYeYouTao/Yuki/blob/main/docs/upgrade-4.0.0.en.md) · [Detailed PR ledger](https://github.com/YuanYeYouTao/Yuki/blob/main/docs/releases/v4.0.0-prs.md)

Yuki 4.0 moves from a QQ-focused bot to one persistent agent shared across QQ, Telegram, Feishu, Lark, personal clients and ACP. They share Person identity, Main, Memory, tools and durable Work. Yuki works in its persistent server environment or, with explicit authorization, uses a computer's shell, files and existing coding agents.

**These are preparation notes, not a publication announcement.** Audited on 2026-11-02: after the actual [v3.9.0](https://github.com/YuanYeYouTao/Yuki/releases/tag/v3.9.0) commit `12de953eb34bab084b6aeb6e4e909f885db17921` through main [`81f102291b737368d00b162a79774c272dcfeb16`](https://github.com/YuanYeYouTao/Yuki/commit/81f102291b737368d00b162a79774c272dcfeb16) (#558), **101 merged PRs and 446 commits**. Every PR is listed below; this documentation refresh is outside the fixed cutoff. The stable download remains 3.9.0.

## Platforms and identity

Feishu/Lark enterprise-app long connections support private chats, groups, topics, mentions, replies and images/files without a public callback. All platforms use shared identity and delivery services. A Person may have multiple accounts or none; transferring an account changes future ownership without rewriting historical events, Memory, Work or receipts. Linked accounts retain separate conversations. Mentions preserve their original position and provenance, and a blocked platform ingress no longer stops the entire Bot. Main PRs: [#458](https://github.com/YuanYeYouTao/Yuki/pull/458)、[#474](https://github.com/YuanYeYouTao/Yuki/pull/474)、[#482](https://github.com/YuanYeYouTao/Yuki/pull/482)、[#484](https://github.com/YuanYeYouTao/Yuki/pull/484)、[#486](https://github.com/YuanYeYouTao/Yuki/pull/486)、[#491](https://github.com/YuanYeYouTao/Yuki/pull/491)、[#525](https://github.com/YuanYeYouTao/Yuki/pull/525)、[#526](https://github.com/YuanYeYouTao/Yuki/pull/526)、[#531](https://github.com/YuanYeYouTao/Yuki/pull/531).

## Desktop and local computers

[Yuki Desktop](https://github.com/Institute-of-Agent-Life/Yuki-Desktop) has its own public Windows, macOS and Linux beta release. Matching development source supports pairing, rich chat, Work, files, Memory, automation, Computer, model configuration and usage. It connects an existing Yuki or deploys a local Bot through Docker. Updating Desktop does not upgrade a remote backend.

One outbound WSS Connector and its original device identity/journal handle local operations. Explicit full access enables shell, files and installed programs as the Connector's OS account, without requiring a coding agent. Optional Codex, Claude Code and ACP keep native authentication and sessions. Discovery, transport, native readiness and real execution are distinct states. The duplicate LocalExecutor is retired while original receipts remain.

Connector **0.4.2 / protocol 4** fixes Windows console windows and the installation-lock byte offset. Desktop-managed connections follow Desktop's lifetime, remain active in the tray and stop on actual quit, without login autostart. Adopting an existing installation preserves credentials, device, instances and journal. Main PRs: [#497](https://github.com/YuanYeYouTao/Yuki/pull/497)、[#510](https://github.com/YuanYeYouTao/Yuki/pull/510)、[#515](https://github.com/YuanYeYouTao/Yuki/pull/515)、[#517](https://github.com/YuanYeYouTao/Yuki/pull/517)、[#518](https://github.com/YuanYeYouTao/Yuki/pull/518)、[#520](https://github.com/YuanYeYouTao/Yuki/pull/520)、[#530](https://github.com/YuanYeYouTao/Yuki/pull/530)、[#533](https://github.com/YuanYeYouTao/Yuki/pull/533)、[#535](https://github.com/YuanYeYouTao/Yuki/pull/535)、[#536](https://github.com/YuanYeYouTao/Yuki/pull/536)、[#556](https://github.com/YuanYeYouTao/Yuki/pull/556)、[#557](https://github.com/YuanYeYouTao/Yuki/pull/557). Desktop PRs belong to their own repository.

Tailscale is optional: install/authenticate on each machine and configure Serve HTTPS on the server host. Desktop supplies guidance rather than bundling Tailscale or handling login. Client and Connector addresses remain independent; changing routes preserves identity without re-pairing or automatic synchronization. Existing SSH/VPN remains usable. See the [guide](https://github.com/YuanYeYouTao/Yuki/blob/main/docs/operations/tailscale-connection.zh-CN.md). Main PRs: [#540](https://github.com/YuanYeYouTao/Yuki/pull/540)、[#542](https://github.com/YuanYeYouTao/Yuki/pull/542).

## Model configuration and recorded usage

Setup and administration share Provider presets, protocol metadata and task requirements. Explicit Profiles serve chat, Memory and SELF; embedding, vision, transcription and search enter the existing bundle. Keys remain in a private sidecar or declared environment source and are not returned with readable configuration. Saved/draft tests and model discovery use the original adapters; actual upstream probes may incur provider charges.

Disabled connections/search never silently fall back. Auxiliary changes accurately report restart requirements; chat retains hot application. Embedding changes create immutable profiles and preserve vectors. One explicit offline migration preserves effective old settings, revision/CAS, disabled modes and paid requests. See the [model migration](https://github.com/YuanYeYouTao/Yuki/blob/main/docs/upgrade-model-config-20261031.md). Main PRs: [#548](https://github.com/YuanYeYouTao/Yuki/pull/548)、[#549](https://github.com/YuanYeYouTao/Yuki/pull/549)、[#550](https://github.com/YuanYeYouTao/Yuki/pull/550)、[#551](https://github.com/YuanYeYouTao/Yuki/pull/551)、[#552](https://github.com/YuanYeYouTao/Yuki/pull/552).

Usage queries original invocations by time window, timezone and recorded provider/model. Renaming today's configuration does not relabel historical calls. Missing input/output/cache accounting is distinct from zero; no price is invented. Desktop separates the common overview from diagnostics. Backend PRs: [#551](https://github.com/YuanYeYouTao/Yuki/pull/551)、[#554](https://github.com/YuanYeYouTao/Yuki/pull/554); Desktop presentation belongs to its PR #36.

## Person superusers and one SOUL

Superuser authority belongs to Person, not accounts, nicknames or pairing. Account transfers do not carry authority. Existing Desktop credentials can authenticate the current Person superuser; other paired people retain authorized personal functions.

**The separate character-owner role is removed.** Shared profile/avatar/SOUL, models and server Computer access use current Person authority. Historical owner rows/receipts are retained without promotion. Trusted local setup explicitly grants its deployer through the original operation; existing remote administrators are verified and granted by the independent operator. Main PRs: [#476](https://github.com/YuanYeYouTao/Yuki/pull/476)、[#545](https://github.com/YuanYeYouTao/Yuki/pull/545)、[#546](https://github.com/YuanYeYouTao/Yuki/pull/546)、[#547](https://github.com/YuanYeYouTao/Yuki/pull/547). The intermediate broad access in [#523](https://github.com/YuanYeYouTao/Yuki/pull/523) is superseded by [#545](https://github.com/YuanYeYouTao/Yuki/pull/545).

One selected SOUL supplies personality, current profile data supplies the name, and program rules are independent. Empty SOUL is valid. Legal new activations adopt changes without rewriting submitted requests, history, identity or fixed tools. Existing deployments explicitly reconcile old personality files and mounts. Main PRs: [#490](https://github.com/YuanYeYouTao/Yuki/pull/490)、[#545](https://github.com/YuanYeYouTao/Yuki/pull/545)、[#555](https://github.com/YuanYeYouTao/Yuki/pull/555).

## Durable work, history and tools

Main, SELF, automation and subagents share Work. Goals, parents, budgets, model requests and external effects remain durable. Lost confirmations are resolved by original IDs. Accepted waits/completion retain their original settlement, and Compact reuses public checkpoints while keeping unobserved tool results on the execution tail. Main PRs: [#470](https://github.com/YuanYeYouTao/Yuki/pull/470)、[#500](https://github.com/YuanYeYouTao/Yuki/pull/500)、[#502](https://github.com/YuanYeYouTao/Yuki/pull/502)、[#504](https://github.com/YuanYeYouTao/Yuki/pull/504)、[#511](https://github.com/YuanYeYouTao/Yuki/pull/511)、[#533](https://github.com/YuanYeYouTao/Yuki/pull/533)、[#544](https://github.com/YuanYeYouTao/Yuki/pull/544)、[#555](https://github.com/YuanYeYouTao/Yuki/pull/555).

Persistent terminals handle files, packages and interactive programs. Unified `send` freezes file versions internally, removing the extra publish-then-send step and permanent transfer copies. Tool text reaches its effective budget with accurate Artifact continuation. `find_contacts` and `find_conversations` separate people/space discovery from history discovery. Main PRs: [#463](https://github.com/YuanYeYouTao/Yuki/pull/463)、[#495](https://github.com/YuanYeYouTao/Yuki/pull/495)、[#539](https://github.com/YuanYeYouTao/Yuki/pull/539).

Explicit recent/search/around history shares one index, pagination and platform/private-group/author/date/media filters. `/ai new` resets context without hiding currently authorized permanent history; results retain original events, conversations and authors. Main PRs: [#489](https://github.com/YuanYeYouTao/Yuki/pull/489)、[#492](https://github.com/YuanYeYouTao/Yuki/pull/492)、[#494](https://github.com/YuanYeYouTao/Yuki/pull/494).

## Media, Memory and maintenance

Media starts with metadata and is read on demand from the shared 24-hour cache. Workspace sticker files/JSON are authoritative; text sends first and background stickers have independent receipts. ASR explicitly selects its protocol. SELF quietly advances real work; follow-up participation remains while old quotas, redundant JEV evaluations and stale-feedback busy loops are removed. Main PRs: [#465](https://github.com/YuanYeYouTao/Yuki/pull/465)、[#467](https://github.com/YuanYeYouTao/Yuki/pull/467)、[#479](https://github.com/YuanYeYouTao/Yuki/pull/479)、[#480](https://github.com/YuanYeYouTao/Yuki/pull/480)、[#481](https://github.com/YuanYeYouTao/Yuki/pull/481)、[#482](https://github.com/YuanYeYouTao/Yuki/pull/482)、[#483](https://github.com/YuanYeYouTao/Yuki/pull/483)、[#496](https://github.com/YuanYeYouTao/Yuki/pull/496)、[#507](https://github.com/YuanYeYouTao/Yuki/pull/507)、[#508](https://github.com/YuanYeYouTao/Yuki/pull/508)、[#526](https://github.com/YuanYeYouTao/Yuki/pull/526)、[#527](https://github.com/YuanYeYouTao/Yuki/pull/527)、[#528](https://github.com/YuanYeYouTao/Yuki/pull/528)、[#529](https://github.com/YuanYeYouTao/Yuki/pull/529).

SQLite uses the same Database's FIFO writer, preparing history, text, files and external work outside short transactions with parallel reads. Vec1 shares transactions, authorizes before candidate selection and reranks real results. Existing vectors move without purchasing embeddings. Manager upgrades use matching source from the selected Bot and real-user connectivity rather than a leftover socket. Main PRs: [#471](https://github.com/YuanYeYouTao/Yuki/pull/471)、[#472](https://github.com/YuanYeYouTao/Yuki/pull/472)、[#477](https://github.com/YuanYeYouTao/Yuki/pull/477)、[#498](https://github.com/YuanYeYouTao/Yuki/pull/498)、[#499](https://github.com/YuanYeYouTao/Yuki/pull/499)、[#519](https://github.com/YuanYeYouTao/Yuki/pull/519)、[#521](https://github.com/YuanYeYouTao/Yuki/pull/521)、[#522](https://github.com/YuanYeYouTao/Yuki/pull/522).
