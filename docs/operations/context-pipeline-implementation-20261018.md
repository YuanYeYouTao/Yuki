## 终审边界

根代理与各owner交叉复核了公共原件/候选、真实Paid恢复、来源/隐私、Social ACK/取消和共享媒体资源。终审额外消除了0133来源更新的双重失效、Guard图片检查的全ID union、纯文本多余媒体序列化；并补“同H读取期间另一候选提交”的确定性SQLite并发回归。缓存源索引受原预算回收，未派发源准备不提升公共prefix。

最后一轮还修正了两项本地实现遗漏：空可见集合仍保留原空ID selection，不能被负向早退吞掉；已失效、换epoch及旧候选晚到的source若不再共享实际当前祖先，沿同一缓存owner回收，避免旧正文通过source引用留存而漏计预算。未接纳source仍可复用，回收不否决合法请求。对应空集合/None、真实触发器失效、换epoch/晚到remember及真实pipeline回归均已补。

L01 的全局锁仍在原 owner；L10 多个独立附件/ASR仍顺序。已有证据证明重复hydrate与同原件下载，尚未证明调整这些并发边界的收益和容量等价，故不加新锁、slot或后台任务。L09退避和L11流式亦未作为本轮产品改动。当前 trace 不分上游TTFB/生成/末字节，Social ACK及本地结算也不能证明客户端首次可见。

生产无本轮写入、无新模型/平台调用，尚无自然流量性能或缓存验收。
