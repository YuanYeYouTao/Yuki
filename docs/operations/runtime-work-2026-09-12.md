## 行为与边界

Yuki 可以登记工作、发送过程说明，再继续调用工具；同一发起人的新要求在安全边界进入当前循环。独立新工作可单独排队，原任务等待后台结果时保留目标和预算。后台回执只唤醒所属工作，不再创建独立 Agent。普通问答无需登记长期工作。

`task_control` 与 `report_progress` 加入固定主工具声明。执行授权仍由本地执行器检查；同步插件和自动化步骤不能借过程说明获得额外发送权限。工具错误是执行结果，不能因此删改下一轮工具声明。

模型/来源合同变化、Rollup 或不可持久化媒体导致快照失效时，明确建立新上下文并保留执行证据，不能承诺永远命中前缀缓存。模型是否正确理解复杂自然语言工作仍需真实使用观察。

旧的独立 sandbox continuation Agent 及自动化恢复器已删除；旧待办退役。持久家目录、已安装环境、artifact、执行回执及登记服务保留。
