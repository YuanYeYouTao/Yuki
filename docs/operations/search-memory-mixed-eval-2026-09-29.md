# `search_memory` 当前混合检索隔离对照（2026-09-29）

本记录比较**未修改的当前检索代码**在同一生产 SQLite 隔离快照上的词法与混合路径。它是候选检索评估，不代表主 Agent 最终回答、真实 QQ 回放或生产请求延迟。问句、事实正文、账号、逐题内部 ID、向量和逐题排名均留在仓库外。

## 固定条件

- SQLite 快照 SHA-256：`d20fd5dabbdf8fcc0f461725678144d2d61b6b2e4f6230e7650b7aae7e794774`。评估前后相同；连接设置 `PRAGMA query_only=ON`，未写生产库、未启动第二个 Bot、未发 QQ。
- 快照有 1,158 条 active、非隔离事实；当前唯一 Qwen DashScope profile 为 `qwen3.7-text-embedding`、dense 1024 维，1,158/1,158 均有该 profile 向量。与评估时生产 Bot 的非密钥 profile 指纹相同；混合请求全部返回 `semantic_status=ready`。
- 检索使用相同授权范围、FTS 候选上限 50、语义候选上限 50、语义相似度下限 0.35、RRF 权重 1/1 和 k=60、最多返回 10 条。向量来自生产配置的 Qwen API；本地评估器按实际 `EmbeddingQueryBuilder` 投影匹配预先生成的查询向量，未用金标调权重或阈值。
- Precision@3 固定以三个位置为分母；Recall@10 先按每题的直接支持事实集合计算，再对可回答题取平均。无答案候选表示检索有返回，**不等于模型编造**。
- 80 问开发集沿用独立复核的私有标注，但题目由事实派生，原审核者曾看到类别线索。另一个冻结的 40 问留出集有 30 条可回答、10 条无直接答案，只有一位新标注者，也不是自然对话随机样本。本次只在当前配置上运行一次留出集，没有对它调参。

## 排序与误报风险

`MemoryRanker.rank_global` 首先按 `relevance_band` 排序。除完全相等命中的 21 档外，纯词法候选的 `semantic_score` 为空，档位是 0；相似度过当前下限的语义候选通常有正档位。这意味着普通纯词法候选即使 FTS 排名高，也会排在所有有正档位的语义候选之后。

实际两组混合结果的 Top 10 **没有纯词法候选**：80 问 Top 10 共 419 个纯语义候选，40 问共 194 个。开发集正例有 254 个原词法 Top 10 候选被挤出，留出集正例有 191 个；两组被挤出的候选中没有已标注的直接支持事实。这说明当前标注集未发现召回损失，不能证明真实查询没有损失。两组混合 Top 3 的纯语义候选分别是 85/240、47/120，其中已标直接支持事实分别只有 5、11 个。无答案题全部返回候选，更需要评估 Agent 的证据判别与最终回答，而不能把相似度当作答案概率。
