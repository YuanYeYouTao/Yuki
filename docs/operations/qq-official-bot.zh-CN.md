# QQ 官方 Bot 接入

Yuki 可以通过 QQ 开放平台的官方机器人接入 QQ 单聊与群聊。连接使用平台的 WebSocket 网关，由 Yuki 主动连出，不需要公网回调地址、域名或证书。它和 SnowLuma（OneBot）是两种独立接入，账号互不相通，可以只用其中一种。

平台规则以 [QQ 开放平台](https://q.qq.com) 现行文档和管理页面为准；下面写的是 Yuki 当前实现所依据的事实与限制。

## 先了解能力限制

- **群里默认只收到 @ 机器人的消息。** 群主把这个群的「机器人可获取的群聊消息范围」改为「获取群内全部消息」后，Yuki 才看得到普通聊天，才能像在其他平台一样自然插话。只收 @ 时，她只能回答 @ 她的消息。
- **群里不能主动发消息。** 每条群消息都必须挂在群里一条已收到的消息（`msg_id`）上。定时任务或 Yuki 自己想说话时，会挂在这个群最新收到的一条消息上；这个群一条消息也没收到过时，回执会如实写「没有可用的投递路径」，不会改发私聊或其他平台。
- **回复有时间窗口和次数限制。** 被动回复窗口单聊约 60 分钟、群聊约 5 分钟，同一条消息下能回复的条数也有限。Yuki 不预先估算，超出时平台返回 40034128，这次发送记为失败，不重试。全量消息模式下群里一直有人说话时，可挂的消息也会持续更新。
- **单聊的主动消息靠「互动召回」。** 定时提醒等没有可回复消息的单聊投递，先按互动召回发送（对方与机器人对话后的 30 天内分四个周期各一条）；召回用完或不支持时再按普通主动消息发送一次，仍被拒就记为失败。
- 群里 @ 某人只能写在 Markdown 消息里；单聊里的 @ 保持为普通文字。
- 目前支持文字、图片、文件、引用回复和 @。语音、视频的原生发送，Markdown 模板、按钮，以及私聊流式消息暂不支持。平台不提供 QQ 号和群名称，Yuki 里看到的是平台给的 openid。

## 注册机器人并取得凭据

1. 用 QQ 登录 [QQ 开放平台](https://q.qq.com)，完成开发者主体注册与认证，按页面创建「QQ 机器人」。
2. 在机器人的开发设置里找到 **AppID** 与 **AppSecret**。AppSecret 只在生成时显示，请妥善保存；重置后旧的立即失效。
3. 如果开发设置里要求配置 IP 白名单，把运行 Yuki 的服务器出口公网 IP 加进去。
4. 在功能配置里开启单聊与群聊相关能力，按需申请平台要求的权限。

## 沙箱与上线

机器人未审核上线前只能在沙箱里联调：

1. 在开放平台的沙箱配置中，把用于测试的 QQ 号和 QQ 群加入沙箱范围。
2. 在 Yuki 的平台设置里填写 AppID、AppSecret，并勾选 **沙箱**。勾选后只有 API 地址改为沙箱地址，凭据相同。
3. 用沙箱里的 QQ 号私聊机器人，或在沙箱群里 @ 机器人，确认能收到回复。

联调完成后在开放平台提交审核、发布上线，再到 Yuki 里取消沙箱。上线后其他用户可以添加机器人、把它拉进群。

## 在 Yuki 中启用

在桌面端「设定 → 平台」的 QQ 卡片中选择「官方 Bot」，填写 AppID、AppSecret，选择是否沙箱后保存。保存时 Yuki 会先用新凭据向平台换取 token 并读取网关地址；凭据被拒时不会关闭正在使用的旧连接，错误原因显示在卡片上。启用后状态会显示是否已连上网关、最近一次成功时间和最近的错误类别。

## 让群主开启全部消息

需要 Yuki 在群里自然参与时，请群主（或有权限的管理员）在 QQ 手机端打开这个群的设置，进入群机器人里 Yuki 对应机器人的设置页，把「机器人可获取的群聊消息范围」改为「获取群内全部消息」。设置项的具体位置随 QQ 版本变化，以 QQ 客户端为准。

开启后：

- @ 机器人的消息和普通消息都会推送给 Yuki，是否被点名按平台标记判断；
- Yuki 自己发出的消息也会被平台推回，Yuki 按自己的发送记录识别并忽略；
- 群里其他机器人的消息不会触发 Yuki 回复。

## 身份

- 同一个机器人里，用户在单聊和各群中的 openid 相同，Yuki 把它当作同一个平台账号。
- openid 与 SnowLuma 接入的 QQ 号是两套账号，Yuki 不会自动合并，也不会据此认定是同一个人。需要把它们归到同一个人时，用现有的 `/ai link` 显式关联。
- 换一个机器人（不同 AppID）时，同一用户的 openid 也会不同。

## 常见失败

| 现象 | 原因与处理 |
| --- | --- |
| 卡片显示凭据被拒 | AppID 或 AppSecret 错误、已重置，或服务器 IP 不在白名单。核对后重新保存。 |
| 群里只回复 @ 的消息 | 群主未开启「获取群内全部消息」。 |
| 定时任务在群里没发出，回执为没有可用投递路径 | 这个群还没有收到过任何消息，平台不允许群主动消息。 |
| 回执为 40034128 | 被动回复窗口已过或次数用尽，等群里或对方有新消息后再发。 |
| 连接反复断开 | 查看卡片上的错误类别；若机器人在开放平台被停用或未上线，沙箱外的账号无法使用。 |
