# 主 Agent 全入口执行统一：验收与交付记录

本地实现和下列定向验证已完成；PR、CI、镜像与生产状态以本记录后续追加的交付结果为准。
当前实现合同见 [主 Agent 执行与恢复](../architecture/main-agent-runtime.md)。

## 修改与边界

- 聊天、自动化和 SDK 复用公共工具执行器；删除只读插件主后端、短期记录降级后端及媒体清空能力。
- 保留真实 origin 和批准交集；工作环境授权与历史读取范围分开，后台读取不从发送目标推导范围。
- 普通回复不强制补 task_control.answer；成功和失败回到 Agent。已有交付和空正文完成均保存结果，外层不重复发。
- SDK 返回有主人的持久句柄，回调超时、分段及重启按原 work 接回；批准变化拒绝继续。
- 同一自动化 run 共享预算，旧 1/2 外层限额不截断主执行。逐次 claim、游标和完成提交使用租约围栏。
- 插件写入后报错保留未知回执，不自动重做；独立计算的嵌套模型调用计入父预算。
- 同一创建调用原子幂等；结构化等价任务查询只给候选，不做语义路由或强制合并。
- 句柄至少保留 7 天；详细历史归档后保留轻量执行标识，避免旧调用变成新工作。

## 本地证据

- 118 项相关测试通过：主入口、自动化、SDK、工作恢复、权限、回执循环和文件交付。
- 最后追加的句柄保留/归档验证所在 14 项入口测试通过。
- 补充回答接口、等待状态、子 Agent 和工作恢复的 63 项定向测试通过。等待调用方的状态不再被分段上限覆盖；按原 work 补充资料并检查重复输入冲突。
- 两种 Provider 请求对照包含真实 messages/input、tools/native_tools；常规续跑保留已提交前缀。
- 27 次请求跨两段或三段继续，原 work、历史和累计消耗不变。
- 实际 Host 插件回调退出后按持久资料恢复，并验证批准版本变化拒绝和接纳前超时不留孤儿。
- Ruff、Linux 目标 Mypy（602 个源文件）通过；测试预算同步为 910，不删除安全门。
