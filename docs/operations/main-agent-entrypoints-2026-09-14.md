## 修改与边界

- 聊天、自动化和 SDK 复用公共工具执行器；删除只读插件主后端、短期记录降级后端及媒体清空能力。
- 保留真实 origin 和批准交集；工作环境授权与历史读取范围分开，后台读取不从发送目标推导范围。
- 普通回复不强制补 task_control.answer；成功和失败回到 Agent。已有交付和空正文完成均保存结果，外层不重复发。
- SDK 返回有主人的持久句柄，回调超时、分段及重启按原 work 接回；批准变化拒绝继续。
- 同一自动化 run 共享预算，旧 1/2 外层限额不截断主执行。逐次 claim、游标和完成提交使用租约围栏。
- 插件写入后报错保留未知回执，不自动重做；独立计算的嵌套模型调用计入父预算。
- 同一创建调用原子幂等；结构化等价任务查询只给候选，不做语义路由或强制合并。
- 句柄至少保留 7 天；详细历史归档后保留轻量执行标识，避免旧调用变成新工作。

合同更新后首次插件自主轮输入 57,806 token，其中缓存 2,816（约 4.87%）；这是冷链单样本，
不能用于宣称暖链达到 95%。暖链及自动化/SDK 分入口实测仍缺自然样本，标记未知。
不发无意义请求保温，不用固定声明哈希替代 Provider 命中统计。

上线快照仍有 3 条既有 suspended work；迁移对无恢复所有者的旧工作明确暂停并保留记录，
没有盲目重跑。原有 Memory 争议事实/后台质量状态不属于此次修复，不能据此声称所有健康字段全绿。
定向故障回放和一次线上发送不保证模型永远不会误解目标，也不代表已证明所有 Provider 故障均消失。
